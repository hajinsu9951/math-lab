### 331 · 짝이 하나씩 맞는가 — 일대일 대응
문제: 번호표를 받아 자리에 앉습니다. 번호 하나에 자리 하나 가 꼭 맞아야 좌석표를 거꾸로 읽어 「이 자리는 몇 번」 을 되찾을 수 있습니다. 어떤 대응이 이렇게 되돌릴 수 있는 대응일까요?
탐구1: 네 대응을 모두 골라 (함수, 높이, 만나는 점, 판정) 을 기록하세요.
탐구2: 일대일이 아닌 대응의 반례가 되는 높이를 찾으세요.
탐구3: 일대일 대응과 역함수의 관계를 손으로 쓰세요.
해설: $x^{2} = 4$ 의 해가 x = 2 와 x = −2 두 개이므로 만나는 점은 2 개입니다. 서로 다른 두 x 가 같은 값으로 가니 되돌릴 수 없습니다 — 그래서 역함수를 만들려면 x ≥ 0 처럼 정의역을 줄여 한 점만 남겨야 합니다.
정답 보기: 모든 수평선과 꼭 한 번씩 만나야 되돌릴 수 있다 — 한 높이에서 두 점을 만나면 「이 값은 어느 x 였나」 를 가릴 수 없으므로 역함수가 없다
오답 보기: 만나는 점이 많을수록 더 좋은 대응이다
오답 보기: 한 높이에서라도 만나면 역함수가 있다
마무리: 모든 높이에서 정확히 한 점 이어야 역함수가 있습니다. $x^{2}$ 를 x ≥ 0 으로 줄이면 한 점만 남아 역함수 √x 가 생깁니다.

### 332 · 닿지 않는 선 — 유리함수의 점근선
문제: 일을 나눠 맡으면 한 사람이 쓰는 시간은 사람 수로 나눈 만큼 줄어듭니다. 사람을 아무리 늘려도 시간이 0 이 되지는 않습니다. 이렇게 닿지 않으면서 한없이 가까워지는 선 은 어디에 생길까요?
탐구1: p, q 를 옮겨 가며 (k, p, q, 점근선, 정의역) 을 여섯 줄 기록하세요.
탐구2: x 를 점근선에 가까이 두었을 때 y 가 어떻게 되는지 찾으세요.
탐구3: k 의 부호가 그래프의 어느 쪽을 정하는지 손으로 쓰세요.
해설: 2 ÷ (1.1 − 1) + 1 = 2 ÷ 0.1 + 1 = 21 입니다. x 를 점근선 x = 1 에 0.1 만큼만 붙였는데 y 가 21 까지 올라갔습니다 — 더 붙이면 끝없이 커지지만 x = 1 자체는 정의역 밖이라 결코 닿지 않습니다.
정답 보기: 점근선은 그래프가 닿지 않으면서 한없이 가까워지는 선 이다 — 세로 점근선의 x 는 분모를 0 으로 만드는 값이라 정의역에서 아예 빠진다
오답 보기: 점근선은 그래프가 지나가는 선이므로 그 위의 점도 정의역에 든다
오답 보기: 점근선은 그래프를 충분히 멀리 늘이면 결국 닿는다
마무리: 한없이 가까워지되 닿지 않습니다. x = 1 을 넣으면 분모가 0 이 되어 값이 아예 없습니다.

### 333 · 여기서부터 시작 — 무리함수의 정의역
문제: 미끄럼틀을 내려오는 데 걸리는 시간은 높이의 제곱근 에 비례합니다. 높이가 음수인 미끄럼틀은 없습니다. 식에 근호가 있으면 그래프가 어디서부터 그려지는지 를 먼저 정해야 합니다. 그 경계는 어떻게 찾을까요?
탐구1: p 를 옮겨 가며 (a, p, q, 정의역, 시작점) 을 여섯 줄 기록하세요.
탐구2: a 를 음수로 바꾸면 무엇이 달라지는지 찾으세요.
탐구3: 정의역을 근호 안의 부등식으로 구하는 절차를 손으로 쓰세요.
해설: 2(x − 3) ≥ 0 에서 양변을 2 로 나누면 x − 3 ≥ 0, 곧 x ≥ 3 입니다. 2 가 양수이므로 부등호는 그대로입니다 — 만약 −2(x − 3) ≥ 0 이었다면 부등호가 뒤집혀 x ≤ 3 이 됩니다.
정답 보기: 정의역은 근호 안 ≥ 0 을 푼 것 이다 — 근호 안의 계수가 음수면 양변을 음수로 나누므로 부등호가 뒤집힌다
오답 보기: 정의역은 늘 x ≥ p 이고 계수의 부호와는 상관이 없다
오답 보기: 근호가 있으면 정의역은 언제나 모든 실수이다
마무리: 근호 안 ≥ 0 을 푸는 것 이 정의역입니다. 음수로 나눌 때 부등호를 뒤집는 것만 빠뜨리지 않으면 됩니다.

### 334 · 조금 흔들었을 뿐인데 — 믿어도 되는 해인가
문제: 두 사람이 각자 잰 값으로 연립방정식을 세워 교점을 구합니다. 재는 데 0.1 쯤의 오차 가 있었습니다. 어떤 연립방정식에서는 해가 거의 그대로인데, 어떤 연립방정식에서는 해가 멀리 달아납니다. 무엇이 그 차이를 만들까요?
탐구1: 벌어진 정도를 줄여 가며 (벌어진 정도, 흔든 양, 해, 증폭률) 을 여섯 줄 기록하세요.
탐구2: 증폭률과 벌어진 정도의 관계를 식으로 짐작하세요.
탐구3: 오차가 있는 자료로 세운 연립방정식에서 조심할 점을 손으로 쓰세요.
해설: 아래 식에서 위 식을 빼면 0.1y = 0.1 이므로 y = 1 입니다. 우변을 0.1 흔들었을 뿐인데 해는 (2, 0) 에서 (1, 1) 로 √2 만큼 움직였습니다 — 증폭률이 약 14 배입니다. 벌어진 정도 0.1 이 분모로 들어가기 때문입니다.
정답 보기: 같은 식이라도 두 직선이 거의 나란하면 작은 오차가 크게 증폭된다 — 해를 쓸 때는 자료의 오차가 몇 배로 커지는지 함께 밝혀야 한다
오답 보기: 해를 구하는 공식이 정확하면 자료의 오차와는 상관이 없다
오답 보기: 벌어진 정도가 작을수록 해가 더 안정된다
마무리: 거의 나란한 연립방정식은 해를 믿기 어렵습니다. 증폭률이 √2 ÷ (벌어진 정도) 이므로 벌어진 정도가 분모로 들어갑니다.

### 335 · 나란한 것들이 만나는 곳 — 소실점
문제: 철길은 끝까지 나란한데 사진에서는 한 점으로 모입니다. 그 점의 자리는 내가 서 있는 곳에 따라 달라질까요, 아니면 선의 방향 만으로 정해질까요?
탐구1: θ 를 바꿔 가며 (θ, 눈높이, 소실점 자리) 를 여섯 줄 기록하세요.
탐구2: 눈높이를 바꾸어도 소실점 자리가 그대로인지 확인하세요.
탐구3: 소실점이 화면 밖으로 달아나는 θ 를 찾아 그 뜻을 손으로 쓰세요.
해설: cot 45° = 1 이므로 220 × 1 = 220 px 입니다. θ 가 90° 면 cot 90° = 0 이라 화면 가운데(0 px), θ 가 0 에 가까워지면 cot θ 가 끝없이 커져 소실점이 화면 밖으로 달아납니다 — 그 달아난 자리를 무한원점이라 부릅니다.
정답 보기: 소실점은 선의 방향 이 정한다 — 선이 어디에 있든 눈높이가 얼마든, 방향이 같으면 모두 같은 소실점으로 모인다
오답 보기: 소실점은 눈높이가 정하므로 눈높이를 올리면 옆으로 옮겨진다
오답 보기: 소실점은 선이 떨어져 있는 간격이 정한다
마무리: 방향이 소실점을 정합니다. θ 가 0 에 가까워지면 cot θ 가 끝없이 커져 소실점이 달아나는데, 그 달아난 자리를 무한원점이라 부릅니다.

### 336 · 접선을 따라가면 답에 닿을까 — 뉴턴 방법
문제: 계산기에 √2 를 누르면 1.41421356… 이 바로 나옵니다. 계산기는 이 값을 어떻게 구했을까요? $x^{2} - 2 = 0$ 을 푸는 식이 따로 없을 때, 접선을 긋고 그것이 x축과 만나는 곳으로 옮겨 가기 를 되풀이하면 어떻게 될까요?
탐구1: 걸음 수를 0 부터 6 까지 올리며 (방정식, 시작점, 걸음, 오차) 를 기록하세요.
탐구2: 오차의 자릿수가 어떻게 변하는지 찾으세요.
탐구3: 시작점을 바꿔 헤매는 예를 하나 찾아 손으로 쓰세요.
해설: f(2) = 2, f′(2) = 4 이므로 x₁ = 2 − 2 ÷ 4 = 1.5 입니다. √2 = 1.41421… 이니 한 걸음에 오차가 0.586 에서 0.086 으로 줄었고, 네 걸음이면 1.6 × $10^{-12}$ 까지 갑니다 — 맞는 자릿수가 걸음마다 대략 배로 늘어납니다.
정답 보기: 접선을 따라가면 맞는 자릿수가 걸음마다 대략 배로 늘어난다 — 다만 시작점에서 접선이 거의 평평하면 멀리 튕겨 나가 헤맨다
오답 보기: 걸음마다 오차가 일정한 양씩 줄어든다
오답 보기: 시작점을 어디로 잡아도 걸음 수만 늘리면 반드시 해에 닿는다
마무리: 자릿수가 배로 늘어납니다. 그래서 네 걸음이면 소수점 아래 열두 자리까지 맞습니다. 시작점을 0.25 로 두면 접선이 평평해 멀리 튕겨 나갔던 것도 함께 기억해 두십시오.

### 337 · 같은 시간에 둘 수 없다 — 그래프 색칠

탐구1: 시간대 수를 4 → 3 → 2 로 줄이며 (시간대 수, 겹친 짝, 배정) 을 기록하세요.
탐구2: 겹침 없이 짤 수 있는 가장 작은 수를 찾으세요.

오답 보기: 꼭짓점이 여섯 개이므로 시간대도 여섯 개 필요하다
마무리: 삼각형 하나가 색 셋을 강제합니다. 시간표·주파수 배정·지도 색칠이 모두 이 문제입니다.

### 338 · 함수는 사라지는데 넓이는 남는다 — 극한과 적분의 순서
문제: 봉우리가 점점 좁고 높아지며 왼쪽으로 달아납니다. 고정한 점 x = 0.5 에서 보면 값이 0 으로 갑니다. 그러면 봉우리 아래 넓이 도 0 으로 갈까요? 극한을 먼저 하고 적분해도 결과가 같을까요?
탐구1: n 을 키워 가며 (n, x, 그 점의 값, 밑변) 을 여섯 줄 기록하세요.
탐구2: 고정한 점에서 값이 0 이 되는 n 을 찾으세요.
탐구3: 넓이가 왜 늘 1 인지 밑변과 높이로 손으로 쓰세요.
해설: $\\frac{1}{2}$ × 0.2 × 10 = 1 입니다. n 이 무엇이든 $\\frac{1}{2}$ × (2/n) × n = 1 이라 넓이는 늘 1 입니다. 그런데 각 점에서의 값은 0 으로 가므로 극한함수는 0 이고 그 넓이는 0 입니다 — lim ∫ fₙ = 1 인데 ∫ lim fₙ = 0 이니 극한과 적분의 순서를 함부로 바꿀 수 없습니다.
정답 보기: 각 점에서 0 으로 가도 넓이는 1 그대로 다 — lim ∫ fₙ = 1 인데 ∫ lim fₙ = 0 이므로 극한과 적분의 순서를 함부로 바꿀 수 없다
오답 보기: 각 점에서 0 으로 가면 넓이도 반드시 0 으로 간다
오답 보기: n 을 키우면 넓이도 n 에 비례해 커진다
마무리: 함수는 사라지는데 넓이는 남습니다. 극한을 먼저 하면 0, 적분을 먼저 하면 1 — 순서를 바꾸려면 따로 조건(고른 수렴 따위)이 필요합니다.

### 339 · 어느 질문을 먼저 던져야 할까 — 정보 이득
문제: 스무고개에서 「이름이 ㄱ 으로 시작하나요」 보다 「생물인가요」 가 훨씬 쓸모 있습니다. 섞여 있는 열매 16 개를 색 으로 나눌지 크기 로 나눌지, 어느 질문이 더 많이 알려 주는지 숫자로 가릴 수 있을까요?
탐구1: 세 가지를 모두 골라 (기준, 나눈 뒤, 정보 이득) 을 기록하세요.
탐구2: 이득이 큰 기준과 거의 0 인 기준의 차이를 찾으세요.
탐구3: 결정트리가 왜 이득이 큰 기준부터 쓰는지 손으로 쓰세요.
해설: 반반이면 두 확률이 모두 0.5 이므로 엔트로피 = −(0.5 × log₂ 0.5 + 0.5 × log₂ 0.5) = 1 비트입니다. 가장 뒤섞인 상태가 1 이고, 한쪽으로 모두 몰리면 0 입니다. 색으로 나누면 1 − 0.544 = 0.456 비트를 얻지만, 크기로 나누면 양쪽이 또 반반이어서 이득이 0 입니다 — 같은 자료라도 질문에 따라 얻는 것이 다릅니다.
정답 보기: 같은 자료라도 어느 기준으로 묻느냐에 따라 얻는 정보가 다르다 — 결정트리는 이득이 가장 큰 질문부터 쓰고, 이득이 0 인 질문은 아예 쓰지 않는다
오답 보기: 자료를 나누기만 하면 어떤 기준이든 뒤섞임이 줄어든다
오답 보기: 묶음의 크기가 같게 나누는 기준이 가장 좋은 기준이다
마무리: 묻는 방식이 얻는 정보를 정합니다. 크기로 나누면 양쪽이 또 반반이어서 뒤섞임이 그대로였습니다.

### 340 · 본 적 없다고 없는 것일까 — 라플라스 보정

탐구2: 곱이 0 이 되는 순간이 왜 위험한지 찾으세요.
탐구3: α 를 너무 크게 하면 무엇이 나빠질지 손으로 쓰세요.
해설: 1 ÷ 100 = 0.01 입니다. 보정 전에는 0 이어서 곱 전체가 0 이었는데, 아주 작은 몫 0.01 을 주자 곱이 살아나 다른 단어의 증거를 계속 쓸 수 있습니다. 분모에 αV = 40 을 함께 더해야 모든 단어의 확률을 합해 1 이 됩니다.
정답 보기: 본 적 없다는 것과 있을 수 없다는 것은 다르다 — 아주 작은 몫을 나눠 주어 곱이 0 이 되는 것을 막아야 다른 단어가 모아 둔 증거가 묻히지 않는다
오답 보기: 학습 자료에 없던 단어는 확률 0 으로 두는 것이 정확하다
오답 보기: α 를 크게 할수록 분류가 늘 좋아진다
마무리: 0 을 막는 아주 작은 몫 이 라플라스 보정입니다. 다만 α 를 너무 크게 하면 모든 단어가 비슷해져 자료에서 배운 차이가 흐려집니다.

### 342 · 줄이면서 무엇을 남길까 — 풀링

탐구3: 어떤 상황에서 어느 방식을 고를지 손으로 쓰세요.

### 343 · 점수를 확률로 — 시그모이드
문제: 모형이 내놓는 점수는 −100 일 수도 1000 일 수도 있습니다. 그런데 「스팸일 확률」 은 0 과 1 사이 여야 합니다. 어떤 수든 0 과 1 사이로 눌러 주면서, 순서는 그대로 지키는 함수가 있을까요?
탐구1: w 를 바꿔 가며 (w, b, x, 확률) 을 여섯 줄 기록하세요.
탐구2: b 를 바꿀 때 경계가 어디로 가는지 찾으세요.
탐구3: w 가 음수이면 무엇이 뒤집히는지 손으로 쓰세요.
해설: −(−4) ÷ 2 = 2 입니다. 그 자리에서 z = 2 × 2 − 4 = 0 이 되고 σ(0) = 0.5 이므로 꼭 판정이 갈리는 지점입니다. b 를 바꾸면 경계가 통째로 옮겨 가고, w 를 키우면 경계는 그대로인 채 곡선만 가팔라집니다.
정답 보기: 판정 경계는 z = 0 이 되는 자리, 곧 x = −b / w 다 — b 는 경계를 옮기고 w 는 경계 둘레에서 확률이 뒤집히는 가파름을 정한다
오답 보기: w 를 키우면 판정 경계도 함께 옮겨 간다
오답 보기: 판정 경계는 늘 x = 0 이다
마무리: 경계는 −b/w, 가파름은 w. 둘이 하는 일이 다릅니다.

### 344 · 붙이고 옮기기를 되풀이하면 — K-평균

### 345 · 놓침과 헛경보는 함께 좋아지지 않는다 — ROC
문제: 병을 가려내는 검사에서 기준을 낮추면 놓치는 사람 이 줄지만 멀쩡한데 양성이라 불리는 사람 이 늘어납니다. 기준 하나로 둘을 동시에 좋게 만들 수 있을까요? 그 맞바꿈을 한 장 에 그릴 수 있을까요?

탐구2: 둘을 동시에 좋게 만들 수 있는지 확인하세요.
탐구3: 떨어진 정도를 바꿔 AUC 가 어떻게 달라지는지 손으로 쓰세요.

정답 보기: 기준값을 옮기는 일은 곡선 위를 미끄러지는 일 이다 — 놓침과 헛경보를 동시에 줄일 수는 없고, 곡선 자체를 올리려면 두 무리를 더 잘 가르는 특징을 찾아야 한다

오답 보기: 기준값을 옮기면 AUC 도 함께 올라간다
마무리: 기준값은 곡선 위의 한 점을 고르는 일 이고, 곡선 전체의 힘은 AUC 가 말해 줍니다.

### 346 · 어느 길로 재야 할까 — 두 가지 거리
문제: 지도에서 두 곳 사이의 거리를 잽니다. 자로 곧게 재면 짧고, 길을 따라 가면 깁니다. 둘 다 「거리」 라고 부르는데, 어느 쪽을 써야 할지는 무엇이 정할까요?
탐구1: 가로·세로를 바꿔 가며 (가로, 세로, 유클리드, 맨해튼) 을 여섯 줄 기록하세요.
탐구2: 두 거리의 차이가 가장 큰 경우를 찾으세요.
탐구3: 두 거리가 같아지는 조건을 손으로 쓰세요.
해설: 3 + 4 = 7 입니다. 곧게 가면 $\\sqrt{3^{2} + 4^{2}} = 5$ 이므로 2 만큼 더 걷는 셈입니다. 직각삼각형에서 빗변은 두 변의 합보다 짧습니다 — 삼각부등식이 바로 이 말이고, 두 거리가 같아지는 것은 한쪽이 0 일 때뿐입니다.

오답 보기: 두 거리는 어느 쪽이 클지 경우에 따라 바뀐다
오답 보기: 격자에서는 맨해튼 거리가 늘 유클리드 거리보다 짧다
마무리: 빗변은 두 변의 합보다 짧습니다. 이것이 삼각부등식이고, 등호는 한쪽이 0 일 때뿐입니다.

### 347 · 두 평균 중 어느 쪽이 클까 — 산술평균과 기하평균
문제: 두 해 동안 값이 각각 2 배 와 8 배 가 되었습니다. 「평균 몇 배씩」 이라고 말해야 할까요? 더해서 2 로 나눈 5 배일까요, 곱해서 제곱근을 씌운 4 배일까요? 두 평균은 왜 다르고, 어느 쪽이 더 클까요?
탐구1: a, b 를 바꿔 가며 (a, b, 산술평균, 기하평균) 을 여섯 줄 기록하세요.
탐구2: 두 평균이 같아지는 때를 찾으세요.
탐구3: 두 평균의 차가 무엇에 따라 커지는지 손으로 쓰세요.
해설: 산술평균 (2 + 8) ÷ 2 = 5, 기하평균 $\\sqrt{2 \\times 8} = 4$ 이므로 차는 1 입니다. 이것은 $\\left(√a - √b\\right)^{2} \\ge 0$ 을 펼친 a + b ≥ 2$\\sqrt{ab}$ 와 같은 말이고, 등호는 √a = √b 곧 a = b 일 때만 성립합니다. 두 해 동안 2 배와 8 배가 되었다면 평균 4 배씩 이 맞습니다 — 4 × 4 = 16 = 2 × 8 이기 때문입니다.
정답 보기: 언제나 산술평균 ≥ 기하평균 이고 등호는 a = b 일 때만 성립한다 — $\\left(√a - √b\\right)^{2} \\ge 0$ 을 펼치면 a + b ≥ 2$\\sqrt{ab}$ 가 되기 때문이다
오답 보기: 두 평균 중 어느 쪽이 큰지는 a, b 에 따라 바뀐다
오답 보기: a 와 b 가 멀어질수록 두 평균이 가까워진다
마무리: $\\left(√a - √b\\right)^{2} \\ge 0$ 하나로 끝납니다. 두 해 동안 2 배와 8 배였다면 평균은 4 배씩입니다.

### 348 · 따로 더해도 될까 — 삼각함수의 덧셈정리
문제: $\\left(a + b\\right)^{2}$ 을 $a^{2} + b^{2}$ 이라 쓰면 틀립니다. 그러면 sin(α + β) 는 어떨까요? sin α 와 sin β 를 그냥 더하면 될까요? 안 된다면 무엇을 더해야 할까요?
탐구1: 각을 바꿔 가며 (α, β, sin(α+β), sinα+sinβ) 를 여섯 줄 기록하세요.
탐구2: 잘못 더한 값이 1 을 넘는 경우를 찾으세요.
탐구3: sin 값이 1 을 넘을 수 없는 까닭을 손으로 쓰세요.
해설: sin 75° = sin 30° cos 45° + cos 30° sin 45° = 0.5 × 0.7071 + 0.8660 × 0.7071 = 0.9659 입니다. 그냥 더하면 0.5 + 0.7071 = 1.2071 이 되어 1 을 넘어 버립니다 — sin 은 단위원 위 점의 y 좌표라 1 을 넘을 수 없으니, 이 하나만으로도 틀린 셈임을 알 수 있습니다.
정답 보기: sin(α + β) = sin α cos β + cos α sin β 다 — 그냥 더한 값은 1 을 넘어 sin 값이 될 수조차 없으니, 이 하나만으로도 틀린 셈임을 알 수 있다
오답 보기: sin(α + β) 와 sin α + sin β 는 각이 작을 때는 정확히 같다
오답 보기: sin 값도 1 보다 클 수 있다
마무리: sin α cos β + cos α sin β 입니다. α = β 로 두면 그대로 sin 2α = 2 sin α cos α 가 됩니다.

### 349 · 나눗셈만으로 최대공약수를 — 유클리드 호제법
문제: 48 cm × 18 cm 종이를 남김없이 똑같은 정사각형으로 자르려 합니다. 가장 큰 정사각형의 한 변은 몇 cm일까요? 두 수를 소인수분해하지 않고, 나눗셈만 되풀이해서 구할 수 있을까요?
탐구1: a, b 를 바꿔 가며 (a, b, 최대공약수, 나눗셈 횟수) 를 여섯 줄 기록하세요.

탐구3: 이 셈이 반드시 멈추는 까닭을 손으로 쓰세요.

정답 보기: 나머지는 나누는 수보다 반드시 작다 — 그래서 나머지가 줄어들다 반드시 0 에 닿고, 그 직전의 나누는 수가 최대공약수다
오답 보기: 두 수를 소인수분해해 보아야만 최대공약수를 알 수 있다
오답 보기: 나눗셈을 되풀이하면 나머지가 커질 수도 있어 멈춘다는 보장이 없다
마무리: gcd(a, b) = gcd(b, a mod b) 를 나머지가 0 이 될 때까지 되풀이할 뿐입니다. 소인수분해보다 훨씬 빠릅니다.

### 350 · 두 조건이 함께 맞는 곳 — 연립부등식
문제: 놀이기구에 「키 120 cm 이상」 과 「키 195 cm 이하」 라는 두 조건이 붙어 있습니다. 탈 수 있는 키는 어디부터 어디까지일까요? 두 조건이 어긋나면 어떻게 될까요?
탐구1: a, b 를 바꿔 가며 (a, b, 해, 구간의 길이) 를 여섯 줄 기록하세요.
탐구2: 해가 없어지는 조건을 찾으세요.
탐구3: 해가 단 하나뿐인 경우를 손으로 쓰세요.
해설: −2 ≤ x ≤ 3 이므로 3 − (−2) = 5 입니다. 연립부등식의 해는 두 해집합의 교집합 이어서, 왼쪽 끝 a 가 오른쪽 끝 b 보다 커지면 겹치는 곳이 사라져 해가 없고, a = b 이면 점 하나만 남아 해가 단 하나입니다.
정답 보기: 연립부등식의 해는 두 해집합의 교집합 이다 — 왼쪽 끝 a 가 오른쪽 끝 b 보다 크면 겹치는 곳이 없어 해가 없고, a = b 이면 점 하나만 남는다
오답 보기: 두 부등식의 해를 모두 합친 것이 연립부등식의 해다
오답 보기: 부등식이 둘 있으면 해는 언제나 있다
마무리: 겹치는 곳만 해입니다. a ≤ b 여야 해가 있고, a = b 이면 단 하나뿐입니다.

### 351 · 스칠까, 뚫고 지날까 — 원의 접선
문제: 공이 벽을 스치고 지나갈 때와 부딪고 들어갈 때가 다릅니다. 원 위의 한 점을 지나는 직선을 조금씩 기울이면, 어느 각에서 원을 꼭 한 점 에서만 스칠까요?
탐구1: 각을 바꿔 가며 (각, 중심까지의 거리, 만나는 점) 을 여섯 줄 기록하세요.
탐구2: 만나는 점이 하나가 되는 각을 찾으세요.
탐구3: 그때 중심까지의 거리가 얼마인지 손으로 쓰세요.
해설: 반지름과 꼭 같은 95 여야 합니다. 중심에서 직선까지의 거리를 d 라 하면 d < 95 이면 두 점에서 만나고, d > 95 이면 아예 만나지 않으며, d = 95 일 때만 한 점에서 스칩니다. 그 수선의 발이 곧 접점이고, 수선과 접선이 수직이므로 접선은 접점에서 그은 반지름과 수직 입니다.
정답 보기: 중심에서 직선까지의 거리가 반지름과 같을 때 만 접한다 — 그 수선의 발이 접점이므로 접선은 접점에서 그은 반지름과 수직이다
오답 보기: 직선이 원 위의 한 점을 지나기만 하면 접선이다
오답 보기: 거리가 반지름보다 멀수록 더 잘 접한다
마무리: 거리 = 반지름 일 때만 접합니다. 그래서 접선은 접점의 반지름과 수직입니다.

### 352 · 칸을 줄이면 무엇이 먼저 사라질까 — 해상도와 표본화
문제: 사진을 작게 저장하려고 칸 수를 줄입니다. 처음에는 거의 그대로인데, 어느 순간부터 무엇을 그린 것인지조차 알 수 없게 됩니다. 더 이상한 일도 있습니다 — 원래 없던 무늬 가 생기기도 합니다. 왜일까요?
탐구1: N 을 줄여 가며 (그림, N, 칸 수, 보이는 줄 수) 를 여섯 줄 기록하세요.
탐구2: 알아볼 수 없게 되는 N 을 그림마다 찾으세요.
탐구3: 없던 무늬가 생기는 N 을 찾아 까닭을 손으로 쓰세요.
해설: 12 × 12 = 144 개입니다. 원본 48 × 48 = 2304 개의 6.25 % 만 남습니다. 줄무늬가 여덟 개인데 가로로 12 칸뿐이면 한 줄무늬 한 주기(두 줄)에 칸이 1.5 개밖에 못 들어가므로 무늬를 담을 수 없고, 그 대신 네 개짜리 가짜 무늬 가 나타납니다 — 이것이 에일리어싱입니다.

오답 보기: 칸을 줄이면 무늬가 흐려질 뿐 개수는 그대로다
오답 보기: 칸을 줄일수록 무늬가 더 또렷해진다
마무리: 한 주기에 칸 둘 이 최소 조건입니다. 그러지 못하면 가짜 무늬가 생깁니다.

### 353 · 걸어서 갈까, 풀어서 갈까 — 정규방정식
문제: 자료에 가장 잘 맞는 직선을 찾습니다. 기울기와 절편을 조금씩 고쳐 가며 내려갈 수도 있고, 식을 세워 한 번에 풀 수도 있습니다. 두 길은 같은 곳에 닿을까요? 어느 쪽이 빠를까요?
탐구1: 「100걸음」을 눌러 가며 (걸음, a, b, 잔차제곱합) 을 여섯 줄 기록하세요.
탐구2: 몇 걸음쯤에서 정규방정식의 답과 거의 같아지는지 찾으세요.
탐구3: 자료가 아주 많아지면 어느 쪽이 유리할지 손으로 쓰세요.
해설: 미지수가 a 와 b 둘이므로 식도 둘입니다. 이 두 식이 바로 정규방정식이고, 미지수가 둘인 연립일차방정식이라 한 번에 풀립니다 — 그래서 되풀이 없이 곧바로 a = Σ(x−x̄)(y−ȳ) / Σ$\\left(x-x̄\\right)^{2}$, b = ȳ − a x̄ 가 나옵니다. 걸어서 가면 400 걸음을 가도 아직 그 자리에 조금 못 미칩니다.
정답 보기: 미지수가 a, b 둘이므로 식도 둘이고, 이 연립일차방정식을 풀면 한 번에 답이 나온다 — 걸어서 가도 같은 곳에 닿지만 수백 걸음이 든다
오답 보기: 걸어서 가는 길과 풀어서 가는 길은 서로 다른 답에 닿는다
오답 보기: 되풀이해 걷는 쪽이 언제나 더 빠르다
마무리: 같은 곳에 닿습니다. 다만 미지수가 적을 때는 풀어서 가는 쪽이 한 번에 끝나고, 미지수가 아주 많아지면 걸어서 가는 쪽이 유리해집니다.

### 354 · 같은 걸음 수로 얼마나 멀리 — 모멘텀
문제: 좁고 긴 골짜기를 내려갑니다. 경사를 그대로 따라가면 가파른 쪽 으로는 금세 바닥에 닿지만 완만한 쪽 으로는 좀처럼 나아가지 못합니다. 앞선 걸음의 관성 을 조금 이어받으면 어떻게 될까요?
탐구1: β 를 0 부터 0.9 까지 바꿔 가며 (α, β, 걸음, 남은 거리, 뒤집힌 횟수) 를 기록하세요.
탐구2: 같은 걸음 수로 가장 멀리 가는 β 를 찾으세요.
탐구3: β 를 너무 크게 하면 무슨 일이 생기는지 손으로 쓰세요.
해설: 약 1.23 입니다. 같은 20걸음인데 β = 0 일 때는 6.41 이 남아 있었습니다. 가로 방향은 기울기가 작아 한 걸음이 0.12x × α 밖에 안 되는데, v ← βv − α∇f 가 그 작은 걸음을 겹쳐 쌓아 주기 때문입니다. 다만 β = 0.9 로 올리면 바닥을 지나쳐 되레 멀어집니다 — 관성도 지나치면 넘칩니다.
정답 보기: 관성은 같은 방향으로 거듭된 작은 걸음을 겹쳐 쌓아 준다 — 그래서 기울기가 작은 완만한 쪽으로도 같은 걸음 수에 훨씬 멀리 나아간다
오답 보기: 관성은 한 걸음의 크기를 키우므로 β 가 클수록 언제나 좋다
오답 보기: 관성을 주면 가파른 쪽으로 더 빨리 내려간다
마무리: 작은 걸음을 겹쳐 쌓습니다. 다만 β 를 0.9 로 올리면 바닥을 지나쳐 되레 멀어집니다.

### 355 · 많이 맞혔다는 말은 잘했다는 뜻일까 — 혼동행렬
문제: 천 명 중 열 명만 걸리는 병이 있습니다. 어떤 검사가 누구에게나 「음성」 이라고만 답한다면, 천 명 중 990 명을 맞힌 셈입니다. 정확도 99 % 입니다. 이 검사를 좋은 검사라고 할 수 있을까요?
탐구1: 양성 비율을 바꿔 가며 (양성 비율, 잡아내는 비율, 정확도, 재현율, 정밀도) 를 여섯 줄 기록하세요.
탐구2: 정확도는 높은데 재현율이 0 인 경우를 찾으세요.
탐구3: 양성 비율이 반반일 때 그 속임수가 통하는지 손으로 쓰세요.
해설: 제대로 넘긴 990 명을 맞혔으니 990 ÷ 1000 = 99 % 입니다. 그런데 재현율은 0 % 입니다 — 실제 환자 10 명 중 한 명도 찾지 못했습니다. 드문 것을 찾는 문제에서는 정확도가 「아무것도 안 하기」에 상을 주므로, 재현율과 정밀도를 반드시 함께 보고해야 합니다.
정답 보기: 드문 것을 찾는 문제에서 정확도는 「아무것도 안 하기」에 상을 준다 — 실제로 찾아낸 비율인 재현율과, 찾았다고 한 것 중 맞은 비율인 정밀도를 함께 보고해야 한다
오답 보기: 정확도가 높으면 좋은 검사이므로 하나만 보아도 된다
오답 보기: 재현율이 올라가면 정확도도 반드시 함께 올라간다
마무리: 정확도 하나로는 속습니다. 네 칸으로 갈라 재현율과 정밀도를 함께 보아야 합니다.
