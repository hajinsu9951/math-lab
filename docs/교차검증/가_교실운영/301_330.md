M1: 대칭을 y = x 로 바꿔 보세요. 무엇이 바뀌나요?
   신호 「통째로 맞바꿉니다」
M2: 이제 원점 대칭으로 바꿔 보세요.
   신호 「이어서 한 것과 같습니다」
M3: 아래 탐구 노트로 마무리하세요 — 한 대칭을 기록하고, 다른 대칭과 견주고, 차이를 판단합니다.
   신호 「탐구 노트 통과」
해볼 것: ① x 축 대칭으로 옮긴 점 적기 ② y = x 대칭으로 옮긴 점 적기 ③ 부호만 바뀌면 1, 자리가 바뀌면 0 적기
손으로: 네 대칭을 (x, y) → (?, ?) 로 정리해 적고, y = x 대칭이 역함수와 이어지는 까닭을 쓰기

### 327 · 어디를 칠할까 — 집합의 연산 네 가지

   신호 「겹친 곳까지 덜어 냅니다」

M3: 아래 탐구 노트로 마무리하세요 — 한 연산을 기록하고, 다른 연산과 견주고, 관계를 판단합니다.

해볼 것: ① 합집합의 원소 수 적기 ② 교집합의 원소 수 적기 ③ |A| + |B| − |A∩B| 가 합집합과 같은지 확인하기

### 328 · 안이냐 밖이냐 — 내분점과 외분점
화면: m 과 n 을 옮기고 내분 · 외분 을 고르면 분모 와 점 P 가 표시됩니다.널빤지를 어디서 나누느냐가 다릅니다. 안에서와 밖에서는 어떻게 다를까요?

   신호 「분모가 0 이 됩니다」
M3: 아래 탐구 노트로 마무리하세요 — 내분점을 기록하고, 외분점을 계산하고, 분모의 뜻을 판단합니다.

### 330 · 하나면 충분하다 — 반례와 충분·필요조건
화면: 명제 를 고르고 살펴볼 수의 범위 를 넓히면 p 는 만족하지만 q 는 만족하지 않는 삐져나온 수(반례) 의 개수가 표시됩니다.흰 백조 사이에 검은 백조 한 마리가 있습니다. 하나면 충분할까요?
M1: 명제를 「4 의 배수이면 2 의 배수」 로 바꿔 보세요.
   신호 「반례가 하나도 없습니다」
M2: 이제 「2 의 배수이면 4 의 배수」 로 바꾸고 범위를 40 이상으로 넓혀 보세요.
   신호 「반례는 사라지지 않습니다」
M3: 아래 탐구 노트로 마무리하세요 — 참인 명제를 기록하고, 거짓인 명제를 확인하고, 증명의 무게를 판단합니다.
   신호 「탐구 노트 통과」
해볼 것: ① 참인 명제에서 반례의 수 적기 ② 거짓인 명제에서 반례의 수 적기 ③ 거짓임을 보이는 데 필요한 반례의 수 적기
손으로: 「4 의 배수 → 2 의 배수」 는 참이고 그 역은 거짓인 것을 쓰고, 충분조건과 필요조건을 이 예로 설명하기
