## 이번 검증이 가르쳐 준 것 — **기계가 만든 가짜 소견 넷**

소견을 적기 전에 **원문을 열어 보는 것** 하나가 세 패스를 모두 구했다.

1. **태그 지우개가 부등호를 먹었다.** `<[^>]+>` 가 `c < 5 … (c >` 를 통째로 지워
   LAB 36 · 54 의 문장이 끊긴 것처럼 보였다 → `</?[A-Za-z][^<>]*>` 로 좁혔다.
2. **이어 붙인 문자열을 앞 토막만 읽었다.** LAB 131 · 140 의 마무리가 잘린 것처럼 보였다.
3. **정답 보기를 늘 첫 줄로 가정했다.** LAB 5 의 정답을 정반대로 적어 냈다.
   → `chk` 의 `pick!==N` 을 읽게 고쳤고, 겸사겸사 ③-1 을 찾아냈다.
4. **백틱 문자열을 못 읽었다.** LAB 1·2·3·21 의 적용 문제가 「글이 없고 그림뿐」으로 보였다.
   → ③-5 소견을 **철회**했다. 두 따옴표를 모두 읽도록 고쳤다.

그리고 한 번은 **고치다가 더 나쁜 결함을 심기도 했다.** ①-2 를 「화면 글이 바뀌었는가」로
고쳤더니, 붙은 직후 스스로 다시 그리는 데모 13종에서 **아무도 만지지 않았는데 단이 열렸다.**
고친 뒤 **같은 기계로 다시 재 본 것**이 유일한 방어였다.
