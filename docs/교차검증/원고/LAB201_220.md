### LAB 201 — 기울기만으로는 부족하다 — 절편까지 배우기
[오늘의 문제] 광고를 한 번도 하지 않은 달 에도 팔리는 양이 있습니다. 그런데 「광고를 늘리면 판매가 늘어난다」를 원점을 지나는 직선 하나로만 적으면, 그 기본 판매량을 적을 자리가 없습니다. 기울기만 아무리 잘 맞춰도 자료 위를 지나갈 수 있을까요?
[화면 안내] 기울기 a 와 절편 b 를 직접 옮기면 손실 이 계산됩니다. 단추 둘로 b 를 0 으로 묶은 최선 과 a, b 를 함께 맞춘 최선 을 불러와 견줄 수 있습니다.치수에 비례하는 부분만으로 옷이 몸에 맞을까요? 기본 길이 는 어디에 적을까요?
[예상 1] 광고를 하나도 하지 않은 달의 판매량이 0 일지 적어 보세요.
[예상 2] 원점을 꼭 지나야 한다면 직선이 자료의 어느 쪽으로 치우칠지 예상하세요.
[예상 3] 절편까지 함께 맞추면 손실이 늘지·줄지·같을지 적으세요.
[미션 1] 「a 만 최적으로 (b = 0 고정)」 를 눌러 보세요. 남은 손실이 얼마인가요?
[미션 2] 이어서 「a 와 b 를 함께 최적으로」 를 눌러 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 손실을 기록하고, 차를 계산하고, 절편의 뜻을 판단합니다.
   └ 달성 신호: 손실이 크게 남습니다
   └ 달성 신호: 손실이 훨씬 줄었습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① b = 0 으로 묶은 손실 적기 ② a, b 를 함께 맞춘 손실 적기 ③ 두 손실의 차 구하기
   └ 손으로 쓸 것: 절편 b 가 이 자료에서 「무엇의 값」인지 한 문장으로 쓰고, b 를 0 으로 묶으면 어긋남이 어느 쪽에 쌓이는지 설명하기
[탐구 1] a 와 b 를 바꿔 가며 6줄 이상 기록하세요. 두 단추로 불러온 값도 꼭 넣으세요.
[탐구 2] 「손실」 열을 보세요. b 를 0 으로 둔 줄과 그렇지 않은 줄의 차이가 보이나요?
[탐구 3] 절편이 현실에서 무엇을 뜻하는지 예를 하나 들어 손으로 쓰세요.
[기록표] a | b | 손실 | b=0 최선 | 둘 다 최선
[힌트] 힌트 — 자료의 x 평균은 3, y 평균은 11 입니다. 최적 직선은 이 평균점을 지납니다.
[적용] 새 문제 — 이 자료에서 기울기가 a = 1.98 일 때 절편 b 는? (소수 둘째 자리)
[적용 답] 5.06 (허용오차 0.1)
[적용 해설] 최적 직선은 자료의 평균점 (3, 11) 을 지납니다. 11 = 1.98 × 3 + b 에서 b = 11 − 5.94 = 5.06 입니다. 화면의 「a 와 b 를 함께 최적으로」가 내놓는 값과 같습니다.
[적용 힌트] 최적 직선이 지나는 한 점을 알면 절편이 바로 나옵니다.
[탐구 노트] 내가 묶고 · 내가 풀고 · 내가 판단한다
  (1) 기록 — 「a 만 최적으로 (b = 0 고정)」 를 누르고 적으세요
  (2) 생각 — 「a 와 b 를 함께 최적으로」 를 누르고, 줄어든 손실을 구하세요
  (3) 판단 — 최적 직선이 자료의 평균점을 지나는지 확인하고 고르세요 (x 의 평균 3, y 의 평균 11)
      빈칸: a = {0} · b = {1} · 손실 = {2}
      빈칸: a = {0} · 손실 = {1} · ①의 손실에서 뺀 차 = {2}
      빈칸: a = {0} · 절편 b = {1} · a × 3 + b = {2}
      보기★ 자료가 원점을 지나지 않으므로 절편 b 가 반드시 필요하다 — b 는 「x 가 0 일 때의 기본값」이고, 최적 직선은 자료의 평균점을 지난다
      보기  절편은 그림을 보기 좋게 하는 값이고 손실과는 관계가 없다
      보기  기울기를 더 잘 맞추면 절편 없이도 손실을 0 으로 만들 수 있다

### LAB 202 — 연 12%는 월 1%와 같을까 — 실효이자율
[오늘의 문제] 두 은행이 똑같이 「연 12%」라고 적어 두었습니다. 한 곳은 1년에 한 번, 다른 곳은 매달 이자를 붙입니다. 적힌 숫자가 같으니 받는 돈도 같을까요? 횟수를 끝없이 늘리면 이자도 끝없이 커질까요?
[화면 안내] 표시된 연이율 과 1년에 이자 붙는 횟수 를 옮기면 실효이자율 과 표시 이율과의 차이 가 계산됩니다. 단추로 매주 붙이기(52번) 를 한 번에 볼 수 있습니다.같은 「연 12%」인데 이자를 붙이는 횟수 가 다르면 어떻게 될까요?
[예상 1] 「연 12% = 월 1%」가 맞는 말인지, 왜 그렇게 생각하는지 적으세요.
[예상 2] 이자 붙는 횟수를 늘릴수록 실효이자율이 어떻게 될지 예상하세요.
[예상 3] 횟수를 끝없이 늘리면 실효이자율이 끝없이 커질지 적어 보세요.
[미션 1] 횟수를 1 로 내려 보세요. 표시된 이율과 실효이자율이 어떤 관계인가요?
[미션 2] 「매주 붙이기」 를 눌러 횟수를 52 로 올려 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 실효이자율을 기록하고, 천장과의 거리를 계산하고, 까닭을 판단합니다.
   └ 달성 신호: 표시 이율과 실효이율이 같습니다
   └ 달성 신호: 한계가 있습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 횟수 1 에서 적기 ② 횟수 52 에서 다시 적기 ③ 천장 값과 견주기
   └ 손으로 쓸 것: (1 + r/k)^k 에서 k 를 키울 때 왜 끝없이 커지지 않는지, 천장이 무슨 수인지 쓰기
[탐구 1] 횟수를 1, 2, 4, 12, 52 로 바꾸며 6줄 이상 기록하세요.
[탐구 2] 「차이」 열을 보세요. 횟수를 늘릴 때 차이가 어떻게 변하나요?
[탐구 3] 「연 12% = 월 1%」가 언제만 맞는 말인지 손으로 쓰세요.
[기록표] 연이율 | 횟수 | 실효이자율 | 차이(%p) | 한계
[힌트] 힌트 — (1 + r/k)^k 는 k 가 커질수록 e^r 에 다가갑니다.
[적용] 새 문제 — 표시 연이율 24% 를 1년에 두 번 붙이면 실효이자율은 몇 %인가요? (소수 둘째 자리)
[적용 답] 25.44 (허용오차 0.06)
[적용 해설] 반년마다 12% 가 두 번 붙으므로 배율은 1 + 0.24 ÷ 2 = 1.12 입니다. 실효이자율은 $1.12^{2} - 1$ = 0.2544 이므로 25.44% — 표시된 24% 보다 1.44%p 높습니다.
[적용 힌트] 반년마다 12% 가 두 번 붙는다고 생각하세요.
[탐구 노트] 내가 세고 · 내가 재고 · 내가 판단한다
  (1) 기록 — 횟수를 1 로 내리고 적으세요
  (2) 생각 — 「매주 붙이기」 를 누르고, 천장까지 남은 거리를 구하세요
  (3) 판단 — 두 실효이자율을 나란히 두고 고르세요
      빈칸: 실효이자율 = {0} % · 표시 이율과의 차이 = {1} %p
      빈칸: 실효이자율 = {0} % · 천장 = {1} % · 천장 − 실효 = {2} %p
      빈칸: 횟수 1 의 실효 = {0} % · 횟수 52 의 실효 = {1} % · 더 큰 쪽이 52 이면 1, 1 이면 0 → {2}
      보기★ 같은 r 이라도 k 가 커지면 실효이자율이 커진다 — 다만 (1 + r/k)^k 가 e^r 로 다가가 멈추므로 e^r − 1 을 넘지 못한다
      보기  횟수를 늘리면 실효이자율이 끝없이 커진다
      보기  이자를 붙이는 횟수는 실효이자율과 아무 관계가 없다

### LAB 203 — 구간이 오르면 손해일까 — 누진세
[오늘의 문제] 「연봉이 올라 세금 구간이 바뀌면 오히려 손해」라는 말을 흔히 듣습니다. 정말 경계를 넘는 순간 전체 소득 에 높은 세율이 붙을까요? 아니면 넘은 부분 에만 붙을까요? 둘은 전혀 다른 이야기입니다.
[화면 안내] 연소득 을 옮기면 소득이 구간으로 잘리고 구간마다 낸 세금 과 한계세율 · 실효세율 이 계산됩니다. 단추 둘로 경계 바로 아래 와 경계를 막 넘긴 자리 를 옮겨 다닐 수 있습니다.한 칸 올라서면 발밑이 통째로 높아질까요, 올라선 만큼 만 높아질까요?
[예상 1] 경계를 1만원 넘겼을 때 세금이 얼마나 늘어날지 예상해 적으세요.
[예상 2] 한계세율과 실효세율 가운데 어느 것이 더 클지 적어 보세요.
[예상 3] 「구간이 오르면 손해」라는 말이 맞는지 지금 생각을 적으세요.
[미션 1] 「구간 경계 바로 아래로」 를 눌러 보세요. 가장 높은 세율이 몇 %인가요?
[미션 2] 이어서 「경계를 막 넘겨서」 를 눌러, 세금이 얼마나 늘었는지 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 경계 앞뒤 세금을 기록하고, 늘어난 양을 계산하고, 그 말이 왜 틀렸는지 판단합니다.
   └ 달성 신호: 15% 구간의 세율만
   └ 달성 신호: 넘은 부분에만
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 경계 바로 아래에서 세금 적기 ② 경계를 넘겨 다시 적기 ③ 두 세금의 차 구하기
   └ 손으로 쓸 것: 늘어난 세금을 늘어난 소득으로 나누어 보고, 그 값이 한계세율과 같은지 쓰기
[탐구 1] 소득을 바꾸며 6줄 이상 기록하세요. 경계 바로 아래와 바로 위를 모두 넣으세요.
[탐구 2] 「한계세율」 과 「실효세율」 두 열을 견주세요. 둘의 크기 관계가 늘 같나요?
[탐구 3] 「구간이 오르면 손해」라는 말이 왜 틀린지 손으로 설명하세요.
[기록표] 소득 | 세금 | 한계세율 | 실효세율 | 차이
[힌트] 힌트 — 높은 세율은 경계를 넘은 부분에만 붙습니다.
[적용] 새 문제 — 소득이 5000만원에서 5100만원 으로 100만원 늘면 세금은 몇 만원 늘어날까요? (경계 위 구간의 세율은 24%)
[적용 답] 24 (허용오차 0.6)
[적용 해설] 늘어난 100만원만 24% 구간에 들어가므로 100 × 0.24 = 24만원이 늘어납니다. 앞선 5000만원에 붙던 세율은 그대로입니다 — 그래서 소득이 늘면 손에 쥐는 돈도 늘어납니다.
[적용 힌트] 새로 생긴 소득이 들어가는 구간만 보세요.
[탐구 노트] 내가 넘기고 · 내가 나누고 · 내가 판단한다
  (1) 기록 — 「구간 경계 바로 아래로」 를 누르고 적으세요
  (2) 생각 — 「경계를 막 넘겨서」 를 누르고, 늘어난 세금을 구하세요
  (3) 판단 — 늘어난 세금을 늘어난 소득으로 나누어 보고 고르세요
      빈칸: 소득 = {0} 만원 · 세금 = {1} 만원 · 한계세율 = {2} %
      빈칸: 소득 = {0} 만원 · 세금 = {1} 만원 · ①에서 늘어난 세금 = {2} 만원
      빈칸: 늘어난 소득 = {0} 만원 · 늘어난 세금 = {1} 만원 · 늘어난 세금 ÷ 늘어난 소득 = {2} %
      보기★ 늘어난 소득이 두 구간에 걸쳐 있어 100만원은 15%, 100만원은 24% 로 갈라 붙었다 — 그래서 평균이 둘 사이인 19.5% 가 된다
      보기  경계를 넘는 순간 전체 소득에 24% 가 붙는다
      보기  세율이 올랐으므로 세금도 두 배가 된다

### LAB 204 — 두 번 바꾸면 손해일까 — 환율과 교차환율
[오늘의 문제] 일본에 가려고 환전을 합니다. 은행에 엔이 없어서 원 → 달러 → 엔 으로 두 번 바꿨습니다. 친구는 원 → 엔 으로 한 번에 바꿨습니다. 두 사람이 받은 엔이 다르다면, 손해의 정체는 환율 일까요 수수료 일까요?
[화면 안내] 원/달러 · 엔/달러 · 한 번 바꿀 때 수수료 를 옮기면 두 번 바꾼 결과 와 바로 바꾼 결과, 그리고 교차환율 과 둘의 차이 가 계산됩니다.창구를 두 번 거치면 무엇을 두 번 내게 될까요?
[예상 1] 수수료가 하나도 없다면 두 길의 결과가 같을지 다를지 적으세요.
[예상 2] 원/엔 환율을 원/달러와 엔/달러로 어떻게 만들지 식으로 적어 보세요.
[예상 3] 수수료를 두 배로 올리면 두 길의 차이가 어떻게 될지 예상하세요.
[미션 1] 수수료를 0 으로 내려 보세요. 두 길의 결과가 같아지나요?
[미션 2] 수수료를 1% 이상 으로 올려 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 결과를 기록하고, 교차환율을 계산하고, 손해의 정체를 판단합니다.
   └ 달성 신호: 나눗셈의 순서만
   └ 달성 신호: 눈에 띄게 손해입니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 수수료 0 에서 두 값 적기 ② 수수료를 올려 다시 적기 ③ 교차환율을 손으로 구해 맞추기
   └ 손으로 쓸 것: 수수료가 0 일 때 두 길이 같아지는 까닭을 (1/a) × b 와 1 ÷ (a/b) 로 보이고, 손해가 무엇에서 오는지 쓰기
[탐구 1] 수수료를 0, 0.5, 1, 2% 로 바꾸며 6줄 이상 기록하세요.
[탐구 2] 「두 번」 과 「바로」 두 열의 차이가 수수료에 따라 어떻게 변하나요?

### LAB 219 — 30% 두 번은 60%일까 — 할인의 함정
[오늘의 문제] 「30% 할인 뒤 추가 30% 할인」이라는 광고를 봅니다. 그러면 60% 할인 일까요? 머릿속으로는 더하고 싶어지는데, 실제로 계산기를 두드려 보면 다른 수가 나옵니다. 할인율은 더해지는 것 일까요 곱해지는 것 일까요?
[화면 안내] 첫 번째 할인 과 두 번째 할인 을 옮기면 최종 가격 과 실제 할인율, 그리고 단순히 더한 값 이 나란히 계산됩니다. 단추로 같은 효과의 한 번 할인 도 볼 수 있습니다.스티커가 겹겹이 붙었습니다. 두 번 깎으면 얼마나 깎인 걸까요?
[예상 1] 30% 두 번이 60% 인지 아닌지, 왜 그런지 적어 보세요.
[예상 2] 첫 할인 뒤에 남는 비율이 얼마인지 적으세요.
[예상 3] 50% 두 번이면 공짜가 될지 예상하세요.
[미션 1] 두 번째 할인을 0 보다 크게 올려 보세요. 단순히 더한 값과 견주면 어떤가요?
[미션 2] 이제 「같은 효과의 한 번 할인 계산」 을 눌러 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 할인율을 기록하고, 실제 할인율을 계산하고, 차이를 판단합니다.
   └ 달성 신호: 적게 깎였습니다
   └ 달성 신호: 곱셈으로 구합니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 두 할인율과 실제 할인율 적기 ② 남는 비율끼리 곱해 손으로 확인하기 ③ 단순 합과의 차 구하기
   └ 손으로 쓸 것: 1 − (1−a)(1−b) 를 전개해 a + b − ab 가 되는 것을 보이고, 늘 단순 합보다 작은 까닭을 쓰기
[탐구 1] 두 할인율을 바꾸며 6줄 이상 기록하세요. 50% 두 번도 꼭 넣으세요.
[탐구 2] 「실제 할인율」 과 「단순 합」 두 열을 견주세요. 차이가 가장 큰 조합은 언제인가요?
[탐구 3] 「30% 두 번 = 60%」 가 왜 틀린지 곱셈으로 손으로 설명하세요.
[기록표] 첫 할인 | 둘째 할인 | 최종 가격 | 실제 할인율 | 단순 합
[힌트] 힌트 — 남는 비율끼리 곱합니다: (1−a)(1−b).
[적용] 새 문제 — 50% 할인 뒤 다시 50% 할인 하면 실제 할인율은 몇 %인가요?

[적용 해설] 남는 비율이 0.5 × 0.5 = 0.25 이므로 실제 할인율은 1 − 0.25 = 0.75, 곧 75% 입니다. 단순히 더한 100% 와 달리 공짜가 되지 않습니다 — 두 번째 50%는 이미 반값이 된 금액의 절반이기 때문입니다.
[적용 힌트] 깎인 쪽이 아니라 남는 쪽을 곱하세요.
[탐구 노트] 내가 깎고 · 내가 곱하고 · 내가 판단한다

  (2) 생각 — 남는 비율 끼리 곱해 보세요
  (3) 판단 — 「같은 효과의 한 번 할인 계산」 을 누른 뒤 고르세요

      빈칸: 실제 할인율 = {0} % · 단순 합 = {1} % · 단순 합이 더 크면 1, 아니면 0 → {2}
      보기★ 1 − (1−a)(1−b) = a + b − ab 이므로 실제 할인율은 단순 합보다 ab 만큼 작다 — 두 번째 할인은 이미 깎이고 남은 금액에만 붙기 때문이다
      보기  할인율은 더해지므로 30% 두 번은 60% 가 맞다
      보기  두 번 깎으면 단순 합보다 더 많이 깎인다

### LAB 220 — 몇 개를 넣어야 100개가 나올까 — 손실률
[오늘의 문제] 재료를 가공하면 20% 가 버려집니다. 완성품 100개가 필요하면 재료를 몇 개 넣어야 할까요? 「100 에 20% 를 더해서 120개」라고 하기 쉬운데, 그렇게 하면 늘 모자랍니다. 왜 그럴까요?

[예상 3] 손실률이 커지면 두 방법의 차이가 어떻게 될지 예상하세요.
