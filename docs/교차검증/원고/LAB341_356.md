### LAB 341 — 외운 것일까 배운 것일까 — 과적합
[오늘의 문제] 시험 범위를 통째로 외운 학생과 원리를 이해한 학생은 그 시험지 에서는 점수가 비슷합니다. 그런데 처음 보는 문제를 주면 갈립니다. 모형도 마찬가지입니다 — 배운 자료에서의 점수 로 실력을 잴 수 있을까요?
[화면 안내] 다항식의 차수 를 올리면 훈련 오차 와 검증 오차 가 함께 표시되고, 훈련 자료만 보고 고르기 를 켜면 검증 자료가 숨겨집니다.빼곡히 칠한 문제집과 새 시험지입니다. 외운 걸까요, 배운 걸까요?

[예상 2] 검증 오차도 같이 줄어들지 적어 보세요.

### LAB 342 — 줄이면서 무엇을 남길까 — 풀링

### LAB 343 — 점수를 확률로 — 시그모이드
[오늘의 문제] 모형이 내놓는 점수는 −100 일 수도 1000 일 수도 있습니다. 그런데 「스팸일 확률」 은 0 과 1 사이 여야 합니다. 어떤 수든 0 과 1 사이로 눌러 주면서, 순서는 그대로 지키는 함수가 있을까요?
[화면 안내] w · b 와 확인할 x 를 옮기면 z = wx + b 와 그 확률, 판정 경계 가 표시됩니다.손잡이를 돌리면 밝기가 부드럽게 바뀝니다. 어떤 수든 0 과 1 사이로 누를 수 있을까요?
[예상 1] z 가 아주 커지면 확률이 어디로 갈지 예상해 적으세요.
[예상 2] z = 0 일 때의 확률을 적어 보세요.
[예상 3] w 를 키우면 곡선이 어떻게 될지 적으세요.
[미션 1] w 를 6 이상 으로 올려 보세요.
[미션 2] 이제 b 를 3 으로 옮겨 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 기본 꼴을 기록하고, 가파른 꼴을 계산하고, 경계의 자리를 판단합니다.
   └ 달성 신호: 판정이 단호해집니다
   └ 달성 신호: 판정 경계가 통째로 옮겨 갔습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① w = 1 · b = 0 · x = 0 에서의 확률 적기 ② w 를 6 으로 올려 x = 0.5 의 확률 적기 ③ w = 2 · b = −4 일 때의 판정 경계 구하기
   └ 손으로 쓸 것: σ(0) = 0.5 가 되는 까닭을 식으로 쓰고, 판정 경계가 x = −b/w 인 까닭을 z = 0 에서 끌어내기
[탐구 1] w 를 바꿔 가며 (w, b, x, 확률) 을 여섯 줄 기록하세요.
[탐구 2] b 를 바꿀 때 경계가 어디로 가는지 찾으세요.
[탐구 3] w 가 음수이면 무엇이 뒤집히는지 손으로 쓰세요.
[기록표] w | b | x | 확률
[힌트] 힌트 — 경계는 z = 0 이 되는 자리, 곧 x = −b / w 입니다.
[적용] 새 문제 — w = 2 · b = −4 일 때 판정 경계 x = −b / w 는 얼마인가요?
[적용 답] 2 (허용오차 0.05)
[적용 해설] −(−4) ÷ 2 = 2 입니다. 그 자리에서 z = 2 × 2 − 4 = 0 이 되고 σ(0) = 0.5 이므로 꼭 판정이 갈리는 지점입니다. b 를 바꾸면 경계가 통째로 옮겨 가고, w 를 키우면 경계는 그대로인 채 곡선만 가팔라집니다.
[적용 힌트] z = 2x − 4 = 0 을 푸세요.
[탐구 노트] 내가 눌러 보고 · 내가 가파르게 하고 · 내가 판단한다
  (1) 기록 — w = 1 · b = 0 · x = 0 으로 두고 확률을 적으세요
  (2) 생각 — w 를 6 이상 으로 올리고 x = 0.5 에서의 확률을 적으세요
  (3) 판단 — 경계의 자리를 고르세요
      빈칸: w = {0} · b = {1} · x = 0 에서의 확률 = {2}
      빈칸: w = {0} · x = {1} · 확률 = {2}
      빈칸: ①의 확률 = {0} · ②의 확률 = {1} · w = 2 · b = −4 일 때의 판정 경계 x = {2}
      보기★ 판정 경계는 z = 0 이 되는 자리, 곧 x = −b / w 다 — b 는 경계를 옮기고 w 는 경계 둘레에서 확률이 뒤집히는 가파름을 정한다
      보기  w 를 키우면 판정 경계도 함께 옮겨 간다
      보기  판정 경계는 늘 x = 0 이다

### LAB 344 — 붙이고 옮기기를 되풀이하면 — K-평균
[오늘의 문제] 학생들을 몇 모둠으로 나눌 때 가까운 사람끼리 묶고 싶습니다. 그런데 모둠의 중심을 모르면 누구를 묶을지 알 수 없고, 누구를 묶을지 모르면 중심도 구할 수 없습니다. 이 닭과 달걀 을 어떻게 풀까요?
[화면 안내] 군집 수 k 를 고르고 한 단계 진행 을 누르면 그때까지의 단계 수 와 중심이 움직인 거리, 묶음 안 거리 제곱합 이 표시됩니다.책상을 모아 모둠을 만듭니다. 가까운 사람끼리 어떻게 묶을까요?
[예상 1] 중심을 모르는 채로 어떻게 시작할 수 있을지 적어 보세요.
[예상 2] 단계를 되풀이하면 거리 제곱합이 어떻게 될지 예상해 적으세요.
[예상 3] 언제 멈추어야 할지 적어 보세요.
[미션 1] 한 단계 진행 을 두 번 눌러 보세요.
[미션 2] 이제 k = 3 으로 바꿔 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 첫 걸음을 기록하고, 다음 걸음을 계산하고, 멈추는 때를 판단합니다.
   └ 달성 신호: 중심이 더 이상 움직이지 않습니다
   └ 달성 신호: 자료가 정해 주지 않고 우리가 정합니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 한 단계 진행을 한 번 눌러 움직인 거리 적기 ② 한 번 더 눌러 다시 적기 ③ 멈추는 때의 움직인 거리 적기
   └ 손으로 쓸 것: 붙이기와 옮기기 두 걸음이 각각 거리 제곱합을 줄이는 까닭을 쓰고, k 를 누가 정하는지와 그 위험을 적기
[탐구 1] 「한 단계 진행」을 누르며 (k, 단계, 움직인 거리) 를 기록하세요.
[탐구 2] 몇 단계 만에 멈추는지 찾으세요.
[탐구 3] k 를 3 으로 바꾸면 무엇이 달라지는지 손으로 쓰세요.
[기록표] k | 단계 | 움직인 거리
[힌트] 힌트 — 거리 제곱합은 단계마다 줄기만 합니다.
[적용] 새 문제 — K-평균은 중심이 움직인 거리 가 얼마가 되면 멈추나요?
[적용 답] 0 (허용오차 0.001)

[적용 해설] 제대로 넘긴 990 명을 맞혔으니 990 ÷ 1000 = 99 % 입니다. 그런데 재현율은 0 % 입니다 — 실제 환자 10 명 중 한 명도 찾지 못했습니다. 드문 것을 찾는 문제에서는 정확도가 「아무것도 안 하기」에 상을 주므로, 재현율과 정밀도를 반드시 함께 보고해야 합니다.
[적용 힌트] 맞힌 사람 수를 전체로 나누세요.
[탐구 노트] 내가 게으르게 하고 · 내가 제대로 하고 · 내가 판단한다
  (1) 기록 — 양성 비율 1 % · 모두 「음성」 으로 두고 적으세요
  (2) 생각 — 체크를 꺼서 제대로 검사 하고 다시 적으세요
  (3) 판단 — 무엇을 함께 보아야 하는지 고르세요
      빈칸: 양성 비율 = {0} % · 정확도 = {1} % · 재현율 = {2} %
      빈칸: 정확도 = {0} % · 재현율 = {1} % · 정확도가 ①보다 낮으면 1 아니면 0 → {2}
      빈칸: ①의 정확도 = {0} % · ①의 재현율 = {1} % · ②의 재현율 = {2} %

### LAB 356 — 논리 회로 탐정
[오늘의 문제] 2층 계단 전등에는 스위치가 아래층과 위층에 하나씩 있습니다. 아래에서 켜고 올라가 위에서 끄고, 다음 사람은 위에서 켜고 내려와 아래에서 끕니다. 스위치 두 개가 서로 상대의 상태를 모르는데 어떻게 이런 일이 가능할까요? 그리고 이 회로의 정체를 뜯어보지 않고 알아낼 방법이 있을까요?
[화면 안내] 상자를 열지 않고 입력을 모두 넣어 보고 출력만 기록하는 것 — 이것이 회로를 알아내는 유일하고 확실한 방법입니다. 여섯 개의 회로를 차례로 조사해 진리표를 채우고, 게이트 블록으로 같은 판정을 내는 회로를 직접 조립해 검사합니다.스위치 두 개의 조합은 네 가지뿐입니다. 한 줄로 이은 회로에서는 둘 다 닫아야 전구가 켜집니다 — 넷 중 한 가지뿐입니다.한 줄로 이은 회로는 둘 다 닫아야 켜집니다 — 전류가 지나갈 길이 하나뿐이기 때문입니다. 갈라서 이으면 하나만 닫아도 켜집니다.켜지는 줄(맨 아래 한 줄)만 모으면 그것이 곧 논리식이고, 같은 것을 게이트 기호 하나로 씁니다.위와 아래는 생김새가 다른데 결과가 같습니다 — (A·B)′ 와 A′+B′. 이것이 드모르간 법칙입니다.
[예상 1] 계단 전등 회로에서 A·B 네 조합 각각에 전등이 켜질지 꺼질지 0과 1로 적으세요.
[예상 2] 왜 그렇게 되는지 전류가 흐르는 길을 근거로 쓰세요. “스위치가 두 개라서”는 근거가 아닙니다.
[예상 3] 두 스위치를 한 줄로 이었을 때(직렬)와 두 갈래로 나눴을 때(병렬)의 진리표가 어떻게 다를지 미리 적으세요.
[미션 1] 회로 하나를 고르고 먼저 예상을 적으세요 — 조합마다 전구를 1·0 으로 찍어 제출한 뒤, 스위치를 눌러 확인합니다.
[미션 2] 게이트 블록을 이어 같은 판정을 내는 회로를 조립하고 「회로 검사」를 누르세요.
[미션 3] 블록 구성을 바꿔 같은 판정을 내는 두 번째 회로를 만들어 다시 검사하세요.
   └ 달성 신호: 진리표를 모두 채웠습니다
   └ 달성 신호: 진리표가 완전히 같습니다
   └ 달성 신호: 다른 조립으로도 합격
   └ 해볼 것: ① 「내 예상」 칸의 1·0 단추 ② 「예상 제출」 ③ 스위치를 눌러 ✓·✗ 확인
   └ 손으로 쓸 것: 전류가 흐르는 길을 따라가며 왜 그렇게 예상했는지 조합마다 한 줄씩 적기
[탐구 1] 여섯 회로를 조사해 6줄 이상 기록하세요. 기본 3종은 반드시 포함합니다.
[탐구 2] “켜지는 조합의 수”와 회로의 이름(직렬·병렬·삼로·다수결)을 표에서 짝지어 보세요. 어떤 규칙이 보이나요?
[탐구 3] 같은 진리표를 내는 서로 다른 조립을 하나 이상 찾아 두 논리식을 나란히 적고, 왜 같은 것인지 손으로 설명하세요. (예: (A·B)′ 와 A′+B′)
[기록표] 회로 | 조사 | 켜지는 조합 | 내 조립 논리식 | 검사
[힌트] 힌트 — 표를 두 부분으로 나눠 보세요. 켜지는 조합이 1가지(직렬)·3가지(병렬)·2가지(삼로)·4가지(다수결). 켜지는 줄만 모아 “+”로 이으면 그것이 곧 논리식입니다.
[적용] 새 문제 — 다섯 사람의 다수결 회로(찬성이 3명 이상이면 전구가 켜짐)를 만들려 합니다. 스위치 5개의 조합은 모두 32가지인데, 그중 전구가 켜지는 조합은 몇 가지일까요?
[적용 답] 16 (허용오차 0.5)
[적용 해설] 찬성 3명 10가지 + 4명 5가지 + 5명 1가지 = 16가지. 32가지의 절반입니다. 이 회로가 바로 4차시에 배울 퍼셉트론 — 가중치 w=(1,1,1,1,1), 임계값 θ=2.5 인 판정기와 완전히 같습니다.
[적용 힌트] 찬성이 3명·4명·5명인 경우를 각각 세어 더하세요. 5개 중 3개를 고르는 경우의 수부터.
[탐구 노트] 없음
