### LAB 41 — 상대도수 — 크기가 다른 두 집단 비교

[화면 안내] 두 반의 인원을 다르게 두고 도수 막대와 상대도수 막대를 나란히 봅니다. 인원이 다르면 «사람 수»로는 비교할 수 없다는 것을, 봉우리가 어디로 옮겨 가는지로 확인합니다.10명인 반과 30명인 반 — 인원이 3배면 막대도 3배가 됩니다. 이것을 «비교»라고 할 수 있을까요?그릇 크기가 달라도 «얼마나 찼는가»는 견줄 수 있습니다. 상대도수가 하는 일이 이것입니다.
[예상 1] 인원이 3배면 막대도 3배가 됩니다. 이것을 «비교»라고 할 수 있을까요?

### LAB 43 — 일차식의 덧셈 — 같은 것끼리만
[오늘의 문제] 3x + 2 를 «5x» 라고 쓰면 왜 틀릴까요? 3과 2는 더해지는데 3x와 2는 왜 묶이지 않을까요? 숫자 대신 타일로 바꿔 놓고 보면 답이 보입니다.
[화면 안내] 타일을 끌어다 놓으면 x 항과 상수항이 따로 모입니다. 정리한 식과 원래 식에 x = 2 를 넣어 값이 같은지 확인하면, 정리가 «값을 바꾸지 않는 일»임을 알 수 있습니다.긴 x 타일과 작은 1 타일은 한 줄로 묶이지 않습니다. 3x + 2 를 5x 라고 쓸 수 없는 까닭입니다.사과는 사과끼리, 귤은 귤끼리 — 같은 것끼리만 모입니다.
[예상 1] 3x + 2 를 더 간단히 할 수 있을까요? 그렇게 생각한 까닭도 적으세요.
[예상 2] «같은 것끼리 묶는다»에서 «같은 것»이란 무엇일까요?
[예상 3] 식을 정리하면 값이 달라질까요?
[미션 1] 타일을 끌어 x 항과 상수항을 각각 모아 보세요.
[미션 2] 정리한 식과 원래 식에 x = 2 를 넣어 값을 견주어 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 합을 기록하고, 두 값을 견주고, 왜 묶이지 않는지 판단합니다.
   └ 달성 신호: 항
   └ 달성 신호: x=2
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① x 항의 합과 상수항의 합 적기 ② x=2 일 때 원래 식과 정리한 식의 값 적기 ③ 두 값이 같은지 보고 판단
   └ 손으로 쓸 것: 3x 와 2 가 왜 묶이지 않는지 타일 그림으로 설명하기
[탐구 1] 여러 식을 만들어 가며 5줄 이상 기록하세요.
[탐구 2] 「x=2 원래 식」과 「x=2 정리한 식」 열을 견주세요. 언제나 같은가요?
[탐구 3] 3x + 2 를 5x 라고 쓰면 왜 틀리는지 x 에 수를 넣어 손으로 보이세요.
[기록표] 문제 | x 항의 합 | 상수항의 합 | 정리한 식 | x=2 원래 식 | x=2 정리한 식
[힌트] 힌트 — 정리는 «모양을 바꾸는 일»이지 «값을 바꾸는 일»이 아닙니다. 값이 달라졌다면 잘못 묶은 것입니다.
[적용] 새 문제 — 5x − 3 + 2x + 8 을 정리했을 때 상수항은?
[적용 답] 5 (허용오차 0.1)
[적용 해설] x 항은 5x + 2x = 7x, 상수항은 −3 + 8 = 5. 정리하면 7x + 5 입니다.
[적용 힌트] 숫자끼리만 더하세요.
[탐구 노트] 내가 모으고 · 내가 넣어 보고 · 내가 판단한다
  (1) 기록 — 타일을 모은 뒤 두 합을 적으세요
  (2) 생각 — x = 2 를 넣었을 때 원래 식과 정리한 식의 값을 적으세요
  (3) 판단 — x 항과 상수항을 보고 고르세요
      빈칸: x 항의 합 = {0} · 상수항의 합 = {1}
      빈칸: 원래 식의 값 = {0} · 정리한 식의 값 = {1} · 두 값의 차 = {2}
      빈칸: x 항의 합 = {0} · 상수항의 합 = {1}
      보기★ 같은 종류의 항끼리만 묶을 수 있다 — x 항과 상수항은 길이가 다른 타일이다
      보기  숫자는 모두 더할 수 있으므로 3x + 2 = 5x 이다

### LAB 44 — 그래프 해석 — 이 그래프는 무슨 이야기일까

[화면 안내] 이야기를 고르고 그래프를 직접 그립니다. 그린 그래프가 이야기와 얼마나 어긋나는지 «평균 어긋남»으로 표시되고, «평평한 구간»과 «0 복귀»를 제대로 넣었는지 따로 확인해 줍니다.걷다가 멈추고 다시 돌아옵니다. 이 이야기를 시간–거리 그래프로 그리면 어떤 모양일까요?올라가다 평평해지고 내려옵니다. 평평한 구간은 멈춘 것일까요, 돌아온 것일까요?
[예상 1] 시간–거리 그래프에서 평평한 구간은 무엇을 뜻할지 적으세요.
[예상 2] «집으로 돌아왔다»는 그래프에서 어떻게 나타날까요?

   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 지금 그린 칸 수와 평균 어긋남 적기 ② 고쳐 그려 어긋남을 줄이기 ③ 평평한 구간과 0 복귀를 넣었는지 확인
   └ 손으로 쓸 것: 평평한 구간이 «멈춤»을 뜻하는 까닭을 기울기로 설명하기
[탐구 1] 이야기를 바꿔 가며 그려 보고 5줄 이상 기록하세요.

[탐구 3] 시간–거리 그래프에서 «기울기»가 무엇을 뜻하는지 손으로 정리하세요.
