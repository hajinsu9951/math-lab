### LAB 321 — 어디까지 믿어도 될까 — 외삽의 위험
[오늘의 문제] 자료에 곡선을 맞추면 자료가 있는 구간 에서는 잘 맞습니다. 그 곡선을 밖으로 늘여 미래를 예측해도 될까요? 차수를 높여 더 잘 맞춘 곡선은 더 믿을 만할까요?
[화면 안내] 맞춤 곡선의 차수 와 예측할 지점 을 옮기면 예측값 과 맞춤 오차, 그 지점이 자료 구간 안인지 밖인지 가 표시됩니다.널빤지가 바다 위에서 뚝 끊깁니다. 여기서 더 나가도 될까요?
[예상 1] 자료에 더 잘 맞는 곡선이 예측도 더 정확할지 예상해 적으세요.
[예상 2] 자료 구간 밖으로 나가면 어떻게 될지 적으세요.
[예상 3] 예측을 발표할 때 함께 밝혀야 할 것을 적어 보세요.
[미션 1] 맞춤 차수를 5 이상 으로 올려 보세요.
[미션 2] 이제 예측 지점을 자료 구간 밖(14 쯤) 으로 옮겨 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 구간 안을 기록하고, 밖에서 계산하고, 믿을 범위를 판단합니다.
   └ 달성 신호: 더 크게 튑니다
   └ 달성 신호: 자료 구간 밖으로 나가자
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 1 차로 구간 안을 예측해 적기 ② 5 차로 구간 밖을 예측해 적기 ③ 두 예측값의 차 구하기
   └ 손으로 쓸 것: 맞춤 오차가 작은 것과 예측이 믿을 만한 것이 다른 이유를 쓰고, 외삽할 때 밝혀야 할 조건을 적기
[탐구 1] 차수와 지점을 바꿔 가며 (차수, 지점, 예측값, 맞춤 오차) 를 여섯 줄 기록하세요.
[탐구 2] 맞춤 오차가 작은데 예측이 크게 튀는 경우를 찾으세요.
[탐구 3] 예측을 믿어도 되는 범위를 손으로 쓰세요.
[기록표] 차수 | 예측 지점 | 예측값 | 맞춤 오차 | 구간 안팎
[힌트] 힌트 — 차수를 높이면 자료에는 더 잘 맞지만 밖에서는 심하게 흔들립니다.
[적용] 새 문제 — 자료가 x = 1 ~ 8 에서 거의 y = 2x 입니다. 1 차 로 맞춘 곡선으로 x = 14 를 예측하면 약 얼마인가요?
[적용 답] 28 (허용오차 1.5)
[적용 해설] y ≒ 2x 이므로 2 × 14 = 28 쯤입니다. 그런데 5 차로 맞추면 자료에는 더 잘 맞으면서도 x = 14 에서는 수십이나 어긋납니다 — 밖으로 늘인 예측은 모형의 가정을 그대로 증폭합니다.

      보기  자료에 가장 잘 맞는 곡선이 예측도 가장 정확하다

### LAB 322 — 만날까 나란할까 — 평행과 수직 조건
[오늘의 문제] 두 직선을 그려 놓고 만나는지 보려면 끝까지 늘여 봐야 할까요? 기울기와 절편만 보고 평행인지 수직인지 한 점에서 만나는지 가릴 수 있을까요?
[화면 안내] 두 직선의 기울기와 절편 을 옮기면 기울기의 곱 과 판정(평행 · 수직 · 한 점 · 같은 직선) 이 표시됩니다.철길은 나란하고 차단기는 직각 으로 지납니다. 만날지 나란할지 어떻게 알까요?
[예상 1] 두 직선이 평행일 조건을 식으로 적어 보세요.
[예상 2] 수직일 조건을 예상해 적으세요.
[예상 3] 기울기가 같고 절편도 같으면 어떻게 되는지 적으세요.
[미션 1] 두 기울기의 곱이 −1 이 되게 맞춰 보세요.
[미션 2] 이제 두 기울기를 같게 하고 절편은 다르게 해 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 수직인 짝을 기록하고, 평행한 짝으로 바꾸고, 조건을 판단합니다.
   └ 달성 신호: 직각으로 만납니다
   └ 달성 신호: 만나지 않습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 수직일 때 두 기울기와 곱 적기 ② 평행일 때 다시 적기 ③ 기울기가 3 인 직선과 수직인 직선의 기울기 구하기
   └ 손으로 쓸 것: 수직 조건 m₁m₂ = −1 을 직각삼각형의 닮음으로 설명하고, 기울기가 0 과 ∞ 인 경우(가로·세로)를 따로 적기
[탐구 1] 기울기를 바꿔 가며 (m₁, m₂, 곱, 판정) 을 여섯 줄 기록하세요.
[탐구 2] 판정이 바뀌는 자리를 찾으세요.
[탐구 3] 기울기로 판정할 수 없는 경우를 손으로 쓰세요.
[기록표] ① 기울기 | ② 기울기 | 곱 | 판정
[힌트] 힌트 — 곱이 −1 이면 수직, 같으면 평행입니다.
[적용] 새 문제 — 기울기가 3 인 직선과 수직인 직선의 기울기는 얼마인가요?
[적용 답] -0.3333 (허용오차 0.01)
[적용 해설] 3 × m = −1 이므로 m = −1/3 ≒ −0.333 입니다. 수직인 두 직선의 기울기는 부호가 반대이고 서로 역수입니다 — 한쪽이 가파르면 다른 쪽은 완만합니다.
[적용 힌트] 3m = −1 을 푸세요.
[탐구 노트] 내가 기울이고 · 내가 맞추고 · 내가 판단한다
  (1) 기록 — 두 직선이 수직 이 되게 맞추고 적으세요
  (2) 생각 — 이제 평행 이 되게 맞추고 적으세요
  (3) 판단 — 두 곱을 나란히 두고 고르세요
      빈칸: ① 기울기 = {0} · ② 기울기 = {1} · 두 기울기의 곱 = {2}
      빈칸: ① 기울기 = {0} · ② 기울기 = {1} · 두 기울기의 곱 = {2}
      빈칸: ①의 곱 = {0} · ②의 곱 = {1} · 기울기가 3 인 직선과 수직인 직선의 기울기 = {2}
      보기★ 곱이 −1 이면 수직, 기울기가 같고 절편이 다르면 평행 이다 — 그려 보지 않고 기울기와 절편만 보고 판정할 수 있다
      보기  기울기가 다르면 언제나 수직이다
      보기  기울기가 같으면 두 직선은 늘 같은 직선이다

### LAB 323 — 얼마나 떨어져 있나 — 점과 직선 사이의 거리
[오늘의 문제] 점을 직선의 식에 넣으면 어떤 수가 나옵니다. 그 수가 곧 거리 일까요? 같은 직선을 2 배 해서 6x − 8y + 4 = 0 으로 적으면 그 수도 2 배가 되는데, 거리가 2 배가 될 리는 없습니다.
[화면 안내] 직선의 계수 a · b · c 와 점의 좌표 를 옮기면 식의 값 과 거리 가 함께 표시됩니다. 분모를 빼고 계산하기 도 있습니다.담장에서 공까지 수직으로 줄자를 댑니다. 얼마나 떨어져 있을까요?
[예상 1] 식에 넣은 값이 거리와 같을지 예상해 적으세요.
[예상 2] 같은 직선을 2 배로 적으면 무엇이 달라질지 적으세요.
[예상 3] 그래서 무엇으로 나누어야 할지 적어 보세요.
[미션 1] 점을 직선 위 로 옮겨 보세요. 거리가 어떻게 되나요?
[미션 2] 이제 「분모를 빼고 계산하기」 를 켜 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 식의 값과 거리를 기록하고, 점을 옮겨 계산하고, 분모의 뜻을 판단합니다.
   └ 달성 신호: 거리가 0 이 되었습니다
   └ 달성 신호: 실제 거리와 어긋납니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 점을 직선 밖에 두고 식의 값과 거리 적기 ② 점을 직선 위로 옮겨 다시 적기 ③ 식의 값 ÷ 거리 구하기
   └ 손으로 쓸 것: 거리 공식의 분모 $\\sqrt{a^{2} + b^{2}}$ 가 법선벡터의 길이인 것을 쓰고, 식을 2 배 해도 거리가 그대로인 까닭을 설명하기
[탐구 1] 점을 옮겨 가며 (식의 값, 거리) 를 여섯 줄 기록하세요.
[탐구 2] 두 값의 비가 일정한지 확인하세요.
[탐구 3] 그 비가 무엇인지 손으로 쓰세요.
[기록표] 직선 | 점 | 식의 값 | 거리
[힌트] 힌트 — 비는 $\\sqrt{a^{2} + b^{2}}$ 입니다.
[적용] 새 문제 — 직선 3x − 4y + 2 = 0 과 점 (2, 1) 사이의 거리는 얼마인가요?
[적용 답] 0.8 (허용오차 0.02)
[적용 해설] |3·2 − 4·1 + 2| ÷ $\\sqrt{9 + 16} = 4$ ÷ 5 = 0.8 입니다. 분자는 식에 넣은 값의 절댓값, 분모는 법선벡터 (3, −4) 의 길이입니다 — 분모로 나누어야 식을 몇 배로 적어도 거리가 같습니다.
[적용 힌트] 분자 4 를 분모 5 로 나누세요.
[탐구 노트] 내가 넣고 · 내가 나누고 · 내가 판단한다
  (1) 기록 — 점을 직선 밖 에 두고 적으세요
  (2) 생각 — 점을 직선 위 로 옮기고 적으세요
  (3) 판단 — 분모의 뜻을 생각하며 고르세요
      빈칸: 식의 값 = {0} · 거리 = {1} · 식의 값 ÷ 거리 = {2}
      빈칸: 식의 값 = {0} · 거리 = {1}
      빈칸: ①의 거리 = {0} · ②의 거리 = {1} · 식의 값을 거리로 바꾸려면 나누어야 하는 수 = {2}
      보기★ 식에 넣은 값은 거리가 아니다 — $\\sqrt{a^{2} + b^{2}}$ 로 나누어야 거리가 된다. 같은 직선을 2 배로 적으면 식의 값도 2 배가 되지만 분모도 2 배가 되어 거리는 그대로다
      보기  식에 넣은 값이 곧 거리다
      보기  직선을 2 배로 적으면 거리도 2 배가 된다

### LAB 324 — 만날까 스칠까 비켜 갈까 — 원과 직선
[오늘의 문제] 원과 직선이 만나는지 알아보려면 연립해서 판별식 을 보아야 합니다. 그런데 더 빠른 방법이 있다고 합니다. 중심에서 직선까지의 거리 하나만 재면 된다는데, 왜 그럴까요?
[화면 안내] 원의 반지름 과 직선의 기울기 · 절편 을 옮기면 중심에서 직선까지의 거리 d 와 판정 이 표시됩니다.젓가락이 접시 가장자리를 살짝 스칩니다. 만날까요, 스칠까요?
[예상 1] 원과 직선이 만나는 경우가 몇 가지일지 적어 보세요.
[예상 2] 거리 d 와 반지름 r 을 견주면 무엇을 알 수 있을지 적으세요.
[예상 3] 접할 때의 조건을 식으로 적어 보세요.
[미션 1] 절편을 옮겨 d 와 r 이 같아지게 해 보세요.
[미션 2] 이제 절편을 더 키워 직선을 멀리 보내 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 점에서 만나는 경우를 기록하고, 접하게 맞추고, 조건을 판단합니다.
   └ 달성 신호: d 와 r 이 같아졌습니다
   └ 달성 신호: 만나지 않습니다
   └ 달성 신호: 탐구 노트 통과

[탐구 1] 절편을 옮겨 가며 (절편, d, 판정) 을 여섯 줄 기록하세요.
[탐구 2] 판정이 바뀌는 d 를 찾으세요.

[적용 힌트] d 와 r 이 같을 때를 떠올리세요.
[탐구 노트] 내가 옮기고 · 내가 맞추고 · 내가 판단한다
  (1) 기록 — 직선이 원과 두 점에서 만나게 두고 적으세요
  (2) 생각 — 절편을 옮겨 접하게 하고 적으세요
  (3) 판단 — 두 거리를 나란히 두고 고르세요
      빈칸: 반지름 r = {0} · 거리 d = {1} · 만나는 점의 수 = {2}

      보기  직선의 기울기가 크면 원과 만난다

### LAB 328 — 안이냐 밖이냐 — 내분점과 외분점

   └ 달성 신호: 분모가 0 이 됩니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 내분점의 분모와 좌표 적기 ② 외분점의 분모와 좌표 적기 ③ m = n 일 때의 분모 적기

  (2) 생각 — 외분 으로 바꾸고 적으세요

### LAB 332 — 닿지 않는 선 — 유리함수의 점근선

[오늘의 문제] 단어의 확률을 곱해 스팸을 가려내는 분류기가 있습니다. 학습 자료에서 한 번도 못 본 단어 가 나오면 그 확률이 0 이 되고, 곱 전체가 0 이 됩니다. 다른 단어들이 모아 둔 증거가 모두 묻히는 셈입니다. 어떻게 막을까요?
[화면 안내] 「축제」 가 나온 횟수 와 보정값 α 를 옮기면 각 단어의 확률 과 세 확률의 곱 이 표시됩니다.한 번도 못 본 낱말입니다. 없다 고 해도 될까요?
[예상 1] 한 단어의 확률이 0 이면 곱이 어떻게 될지 적어 보세요.
[예상 2] 본 적 없다는 것과 있을 수 없다는 것의 차이를 적으세요.
[예상 3] α 를 너무 크게 하면 무엇이 나빠질지 예상해 적어 보세요.
[미션 1] 「축제」 가 나온 횟수를 0 으로 내려 보세요 (α 는 0 그대로).
[미션 2] 이제 α 를 1 로 올려 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 0 이 된 자리를 기록하고, 보정한 값을 계산하고, 보정의 뜻을 판단합니다.
   └ 달성 신호: 곱 전체가 0 이 되었습니다
   └ 달성 신호: 아주 작은 값으로 살아났습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 횟수 0 · α = 0 에서 확률 적기 ② α 를 1 로 올려 확률과 분모 적기 ③ 곱이 0 이 아니게 되었으면 1 적기
   └ 손으로 쓸 것: P = (count + α) / (N + αV) 에서 분모에도 αV 를 더해야 확률의 합이 1 이 되는 것을 쓰고, α 가 너무 크면 무엇이 흐려지는지 적기
[탐구 1] 등장 횟수를 0 으로 두고 α 를 올리며 (횟수, α, 확률, 곱) 을 기록하세요.
[탐구 2] 곱이 0 이 되는 순간이 왜 위험한지 찾으세요.
[탐구 3] α 를 너무 크게 하면 무엇이 나빠질지 손으로 쓰세요.
[기록표] 등장 횟수 | α | P(축제) | 곱
[힌트] 힌트 — 분모에도 αV 를 더해야 확률의 합이 1 이 됩니다.
[적용] 새 문제 — 전체 60 · 어휘 40 · 등장 횟수 0 일 때 α = 1 이면 P(축제) = (0 + 1) ÷ (60 + 1 × 40) 입니다. 값은 얼마인가요?
[적용 답] 0.01 (허용오차 0.001)
[적용 해설] 1 ÷ 100 = 0.01 입니다. 보정 전에는 0 이어서 곱 전체가 0 이었는데, 아주 작은 몫 0.01 을 주자 곱이 살아나 다른 단어의 증거를 계속 쓸 수 있습니다. 분모에 αV = 40 을 함께 더해야 모든 단어의 확률을 합해 1 이 됩니다.
[적용 힌트] 분모는 60 + 1 × 40 입니다.
[탐구 노트] 내가 0 을 만들고 · 내가 되살리고 · 내가 판단한다
