### LAB 261 — 가장 퍼진 방향 — 주성분과 차원 축소
[오늘의 문제] 키와 몸무게처럼 서로 얽힌 두 특징 이 있습니다. 둘 중 하나를 버리면 정보가 많이 사라집니다. 그런데 새 축 하나 를 잘 고르면 거의 그대로 남길 수 있다고 합니다. 그 축은 어떻게 찾을까요?
[화면 안내] 상관 정도 와 내려 찍을 방향 을 옮기면 자료가 그 축에 내려 찍히고 「퍼진 정도(분산)」 가 표시됩니다. 단추로 가장 퍼지는 방향 을 찾을 수 있습니다.그림자가 모두 한 방향 으로만 깁니다. 퍼짐이 한 방향뿐이면 축 하나로 적을 수 있을까요?
[예상 1] 두 특징이 많이 얽혀 있을 때 자료가 어떤 모양으로 놓일지 예상해 적으세요.
[예상 2] 어느 방향으로 내려 찍으면 가장 넓게 퍼질지 적어 보세요.
[예상 3] 축을 하나로 줄이면 무엇을 잃고 무엇을 지키는지 적으세요.

[미션 3] 아래 탐구 노트로 마무리하세요 — 한 방향의 분산을 기록하고, 가장 퍼지는 방향과 견주고, 축을 줄여도 되는지 판단합니다.

   └ 손으로 쓸 것: 분산이 가장 커지는 방향이 왜 공분산행렬의 고유벡터인지 쓰고, 두 고윳값의 합이 전체 분산과 같은 까닭을 설명하기

### LAB 262 — 비를 보면 안다 — 수렴판정
[오늘의 문제] 항을 끝없이 더하는데 더해 보지 않고 모일지 흩어질지 알 수 있을까요? 이웃한 두 항의 비 하나만 보면 된다고 합니다. 그런데 그 비가 꼭 1 일 때는 아무 말도 못 한다고 합니다. 왜 그럴까요?

[예상 3] 비가 꼭 1 이면 어떻게 될지 적어 보세요.

### LAB 263 — 0 으로 가는데도 무한 — p-급수와 적분판정
[오늘의 문제] 1 + 1/2 + 1/3 + 1/4 + … 은 항이 0 으로 갑니다. 그런데 이 합은 끝없이 자랍니다. 반면 1 + 1/4 + 1/9 + … 는 멈춥니다. 항이 0 으로 가는 것만으로는 왜 모자랄까요?
[화면 안내] 지수 p 와 더한 항의 수 를 옮기면 막대(부분합)와 곡선 아래 넓이(적분값) 가 나란히 표시됩니다.가로등이 점점 작아지며 끝없이 이어집니다. 하나하나가 작아지면 합도 멈출까요?
[예상 1] 항이 0 으로 가면 합도 반드시 멈출지 예상해 적으세요.
[예상 2] p 가 1 일 때와 2 일 때 합이 어떻게 달라질지 적으세요.
[예상 3] 막대와 곡선 아래 넓이 가운데 어느 쪽이 클지 적어 보세요.
[미션 1] p = 1 로 두고 항의 수를 300 이상 으로 키워 보세요.
[미션 2] 이제 p 를 2 로 올려 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 두 수를 기록하고, p 를 바꿔 계산하고, 경계가 되는 p 를 판단합니다.
   └ 달성 신호: 합은 계속 자랍니다
   └ 달성 신호: 울타리를 넘지 못합니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① p = 1 · 300항의 부분합과 적분값 적기 ② p = 2 로 바꿔 두 수 적기 ③ 경계가 되는 p 적기
   └ 손으로 쓸 것: 막대가 곡선보다 높다는 그림으로 Σ1/n 의 발산을 설명하고, p > 1 에서 넓이가 유한한 까닭을 적분으로 쓰기
[탐구 1] p 를 바꿔 가며 (부분합, 적분값) 을 여섯 줄 기록하세요.
[탐구 2] 두 값이 함께 자라는 p 와 함께 멈추는 p 를 가르세요.
[탐구 3] 적분이 급수를 가두는 방법을 손으로 쓰세요.
[기록표] p | 항 수 | 부분합 | 적분값
[힌트] 힌트 — 1/xᵖ 아래 넓이가 유한한지 보면 급수의 운명이 보입니다.
[적용] 새 문제 — p = 3 일 때 ∫₁∞ x−3 dx 의 값은 얼마인가요?
[적용 답] 0.5 (허용오차 0.02)
[적용 해설] ∫₁^∞ x^(−3) dx = [x^(−2)/(−2)]₁^∞ = 0 − (−1/2) = 1/2 입니다. 넓이가 0.5 로 유한하니 Σ1/$n^{3}$ 도 유한합니다 — p > 1 이면 언제나 모입니다.
[적용 힌트] x^(−3) 의 부정적분을 구해 1 부터 무한까지 넣으세요.
[탐구 노트] 내가 더하고 · 내가 재고 · 내가 판단한다

  (2) 생각 — p 를 2 로 올리고 다시 적으세요
  (3) 판단 — 두 부분합을 나란히 두고 고르세요
      빈칸: p = {0} · 부분합 = {1} · 곡선 아래 넓이 = {2}

      빈칸: ①의 부분합 = {0} · ②의 부분합 = {1} · 모이기 시작하는 p 의 경계 = {2}
      보기★ 항이 0 으로 가는 것만으로는 모자라고 1/xᵖ 아래 넓이가 유한해야 한다 — 그 경계가 p = 1 이고, 막대가 곡선보다 높으니 넓이가 무한하면 합도 무한하다

### LAB 264 — 항을 늘려도 나빠진다 — 수렴반경
[오늘의 문제] 다항식으로 함수를 흉내 낼 때 보통 항을 늘리면 더 정확해집니다. 그런데 어떤 x 에서는 항을 늘릴수록 오히려 더 멀어집니다. 그 경계는 어디일까요?
[화면 안내] x 와 항의 수 를 옮기면 $1 + x + x^{2}$ + … 의 부분합과 참값 1/(1−x) 가 함께 그려지고 오차가 표시됩니다.가운데는 반듯한데 가장자리는 휘어 보입니다. 어디서부터 틀어질까요?
[예상 1] 항을 늘리면 언제나 더 정확해질지 예상해 적으세요.
[예상 2] x = 0.5 와 x = 1.2 에서 부분합이 어떻게 달라질지 적으세요.
[예상 3] 경계가 되는 x 를 적어 보세요.
[미션 1] x = 0.5 로 두고 항의 수를 12 이상 으로 키워 보세요.
[미션 2] 이제 x 를 1.2 로 올려 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 반경 안의 값을 기록하고, 반경 밖에서 계산하고, 경계를 판단합니다.
   └ 달성 신호: 참값에 딱 붙습니다
   └ 달성 신호: 오히려 멀어집니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① x = 0.5 · 12항의 부분합과 참값 적기 ② x = 1.2 로 올려 두 수 적기 ③ 참값에 다가간 쪽 고르기
   └ 손으로 쓸 것: $1 + x + x^{2}$ + … = 1/(1−x) 가 |x| < 1 에서만 성립하는 까닭을 부분합의 식으로 쓰고, 반경 밖에서 멀어지는 까닭을 설명하기
[탐구 1] x 를 바꿔 가며 (부분합, 참값, 오차) 를 여섯 줄 기록하세요.
[탐구 2] 항을 늘릴 때 오차가 줄어드는 x 와 커지는 x 를 가르세요.

[기록표] x | 항 수 | 부분합 | 참값 | 오차
[힌트] 힌트 — 부분합은 ($1 - x^{n}$)/(1 − x) 입니다. $x^{n}$ 이 어디로 가는지 보세요.
[적용] 새 문제 — x = −0.8 일 때 참값 1/(1 − x) 은 얼마인가요?
[적용 답] 0.5556 (허용오차 0.01)
[적용 해설] 1/(1 − (−0.8)) = 1/1.8 = 0.5556 입니다. |−0.8| < 1 이라 반경 안이므로 항을 늘릴수록 부호가 번갈아 흔들리면서도 이 값에 붙습니다.
[적용 힌트] 분모의 1 − x 를 먼저 계산하세요.
[탐구 노트] 내가 늘리고 · 내가 재고 · 내가 판단한다
  (1) 기록 — x = 0.5 · 항의 수 12 이상 으로 두고 적으세요
  (2) 생각 — x 를 1.2 로 올리고 다시 적으세요 (항의 수는 그대로)
  (3) 판단 — 두 부분합을 참값과 견주고 고르세요

### LAB 277 — 한 점에서 만나려면 — 체바 정리

[예상 3] 비 하나만 바꾸면 교점이 어떻게 될지 적으세요.

### LAB 280 — 세 점이 한 줄에 — 오일러 직선
[오늘의 문제] 삼각형의 중심 넷은 따로 있습니다. 그런데 그 가운데 셋(외심 · 무게중심 · 수심) 은 언제나 한 직선 위에 있고, 더 놀랍게도 거리의 비까지 늘 1 : 2 라고 합니다. 정말 그럴까요?
[화면 안내] 꼭짓점 C 를 옮기면 네 중심이 움직이고 OG · GH · 그 비 · 내심이 벗어난 정도 가 표시됩니다.돌 셋이 한 줄 로 놓였습니다. 삼각형의 중심들도 그럴까요?
[예상 1] 세 중심이 한 직선 위에 있는 것이 우연일지 적어 보세요.
[예상 2] OG 와 GH 의 비가 삼각형에 따라 달라질지 적으세요.
[예상 3] 내심도 그 직선 위에 올 때가 있을지 적어 보세요.
[미션 1] C 를 옮겨 두 변의 길이가 같게 만들어 보세요 (C ≒ (0.4, −0.4)).
[미션 2] 이제 정삼각형 에 가깝게 해 보세요 (C ≒ (1.9, −1.3)).
[미션 3] 아래 탐구 노트로 마무리하세요 — 비를 기록하고, 이등변일 때 내심을 확인하고, OH 를 판단합니다.
   └ 달성 신호: 같은 직선 위에 올라왔습니다
   └ 달성 신호: 직선 자체가 사라졌습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① OG · GH · 그 비 적기 ② 이등변으로 만들어 내심이 벗어난 정도 적기 ③ OG = 1.2 일 때 OH 구하기
   └ 손으로 쓸 것: GH : OG 가 언제나 2 : 1 인 것을 적고, 정삼각형에서 직선이 사라지는 까닭을 설명하기
[탐구 1] C 를 옮겨 가며 (OG, GH, 비) 를 여섯 줄 기록하세요.
[탐구 2] 비가 삼각형에 따라 달라지는지 확인하세요.
[탐구 3] 내심이 그 직선 위에 오는 경우를 손으로 쓰세요.
[기록표] C | OG | GH | 비 | I 벗어남
[힌트] 힌트 — H = 3G − 2O 입니다. 이 식에서 비가 바로 보입니다.
[적용] 새 문제 — 어떤 삼각형에서 OH = 4.5 입니다. OG 는 얼마인가요?
[적용 답] 1.5 (허용오차 0.02)
[적용 해설] OG : GH = 1 : 2 이므로 OH = OG + GH = 3 × OG 입니다. 따라서 OG = 4.5 ÷ 3 = 1.5 입니다. 어떤 삼각형이든 무게중심은 외심과 수심을 1 : 2 로 나눕니다.
[적용 힌트] OH 가 OG 의 몇 배인지 먼저 구하세요.
[탐구 노트] 내가 옮기고 · 내가 재고 · 내가 판단한다

  (2) 생각 — C 를 옮겨 두 변의 길이가 같게 하고 적으세요
  (3) 판단 — 두 번의 비를 견주어 보고 고르세요
