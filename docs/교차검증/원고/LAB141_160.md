### LAB 141 — 그릇에 물이 얼마나 들어갈까 — 회전체와 원판
[오늘의 문제] 병이나 그릇처럼 둥글게 돌아가는 모양 의 부피를 재려면 어떻게 할까요? 공식이 없는 모양이라도, 얇게 자르면 아는 모양이 됩니다.
[화면 안내] 그릇 모양(원뿔 · 포물선 그릇 · 원기둥)과 원판의 개수 n, 높이 h 를 바꾸면 원판 합 과 정확한 값과의 오차 가 계산됩니다. n 을 늘려 계단이 매끄러워지는 것을 볼 수 있습니다.이 그릇에 물이 얼마나 들어갈까요? 공식이 없는 모양 의 부피는 어떻게 잴까요?
[예상 1] 잘라 낸 한 장의 원판은 어떤 모양일지, 그 부피를 어떻게 구할지 적으세요.
[예상 2] n 을 늘리면 합이 어떻게 될지 예상하세요.
[예상 3] 반지름이 일정하면 어떤 입체가 될지 적어 보세요.
[미션 1] 원판 개수 n 을 크게 늘려 참값에 다가가 보세요.
[미션 2] 모양을 「③ r = 1」 로 바꿔 보세요. 어떤 입체가 되나요?
[미션 3] 아래 탐구 노트로 마무리하세요 — 합을 기록하고, n 을 늘려 견주고, 식을 판단합니다.
   └ 달성 신호: 오차가 0.005 아래
   └ 달성 신호: 반지름이 일정하면 원기둥
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① n 이 작을 때의 합과 오차 적기 ② n 을 크게 해 다시 적기 ③ 모양을 바꿔 다시 확인
   └ 손으로 쓸 것: 원판 한 장의 부피가 $\\mathrm{πr}^{2}$Δx 임을 쓰고, 그 합의 극한이 ∫πr²dx 가 되는 까닭을 설명하기
[탐구 1] 모양과 n 을 바꿔 가며 5줄 이상 기록하세요.
[탐구 2] 「오차」 열을 보세요. n 을 늘리면 어떻게 되나요?
[탐구 3] 원판 한 장의 부피부터 시작해 식을 손으로 세우세요.
[기록표] 모양 | n | 높이 | 원판 합 | 오차
[힌트] 힌트 — 원판 한 장은 밑면이 원이고 두께가 Δx 인 아주 납작한 원기둥입니다.
[적용] 새 문제 — y = x 를 x축 둘레로 0 부터 2 까지 돌린 입체(원뿔)의 부피는? (소수 둘째 자리)
[적용 답] 8.38 (허용오차 0.04)
[적용 해설] V = π∫₀² $x^{2}$ dx = π·8/3 = 8π/3 ≒ 8.38. 밑면 반지름 2, 높이 2 인 원뿔이므로 (1/3)·$π \\cdot 2^{2} \\cdot 2$ 와 같습니다.
[적용 힌트] 원판 한 장은 π(반지름)²·Δx 입니다. 반지름이 x 이므로 $\\mathrm{πx}^{2}$ 을 0 부터 2 까지 적분하세요.
[탐구 노트] 내가 자르고 · 내가 늘리고 · 내가 판단한다
  (1) 기록 — 원판 개수를 적게 두고 합과 오차를 적으세요
  (2) 생각 — n 을 다섯 배 넘게 늘려 오차를 다시 구하세요
  (3) 판단 — 모양을 바꿔 같은 것을 해 본 뒤 고르세요
      빈칸: n = {0} · 원판 합 = {1} · 오차 = {2}
      빈칸: 새 n = {0} · 오차 = {1} · ①의 오차보다 줄었으면 1, 아니면 0 → {2}
      빈칸: 새 n = {0} · 원판 합 = {1} · 오차 = {2}
      보기★ 원판 한 장이 π $r^{2}$Δx 이고, 그 합의 극한이 ∫π $r^{2}$ dx 다 — 공식이 없는 모양도 잘라서 더하면 된다
      보기  원판으로는 둥근 그릇의 부피를 구할 수 없다
      보기  n 을 늘리면 합이 끝없이 커진다

### LAB 142 — 열 명에서 세 명 뽑기 — 조합과 파스칼 삼각형
[오늘의 문제] 반 10명에서 청소 당번 3명을 뽑습니다. 몇 가지일까요? 10 × 9 × 8 = 720 … 이라고 하면 너무 많이 센 것 입니다. 왜 그럴까요?
[화면 안내] 줄 번호 n 과 뽑는 개수 r 를 바꾸면 C(n, r) 와 바로 위 두 수 가 함께 표시됩니다. 「한 줄을 모두 더하기」로 $2^{n}$ 도 확인할 수 있습니다.열 명에서 세 명 — 뽑는 순서 가 다르면 다른 경우일까요?
[예상 1] 10 × 9 × 8 은 무엇을 센 수일지 적어 보세요.
[예상 2] 같은 세 명을 몇 번씩 센 것일지 예상하세요.
[예상 3] 파스칼 삼각형에서 바로 위 두 수와 아래 수의 관계를 예상해 적으세요.
[미션 1] n 을 10, r 을 3 으로 맞춰 보세요.
[미션 2] 「한 줄을 모두 더하기」 를 눌러 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 값을 기록하고, 위 두 수와 견주고, 항등식을 판단합니다.
   └ 달성 신호: 10명에서 3명을 뽑는
   └ 달성 신호: 부분집합의 개수와 같습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 지금 C(n, r) 과 위 두 수 적기 ② 위 두 수를 더해 보기 ③ 다른 자리로 옮겨 다시 확인
   └ 손으로 쓸 것: 한 사람을 정해 「그를 뽑는다 / 안 뽑는다」로 나누면 C(n,r) = C(n−1,r−1) + C(n−1,r) 가 되는 까닭을 쓰기
[탐구 1] n 과 r 을 바꿔 가며 5줄 이상 기록하세요.
[탐구 2] 「C(n,r)」와 「합」 열을 견주세요. 늘 같은가요?
[탐구 3] 왜 그렇게 되는지 「한 사람을 정해」 설명하세요.
[기록표] n | r | C(n,r) | 위 두 수 | 합
[힌트] 힌트 — 한 사람을 콕 집어 「뽑히는 경우」와 「안 뽑히는 경우」로 나눠 보세요.
[적용] 새 문제 — 10명에서 3명 을 뽑는 방법은 모두 몇 가지일까요?
[적용 답] 120 (허용오차 0.5)
[적용 해설] C(10,3) = (10×9×8)/(3×2×1) = 720/6 = 120. 720 은 순서까지 센 수이고, 같은 세 명이 3! = 6 번씩 세어졌습니다.
[적용 힌트] 10 × 9 × 8 을 구한 뒤, 같은 세 명이 몇 번 세어졌는지로 나누세요.
[탐구 노트] 내가 뽑고 · 내가 더하고 · 내가 판단한다
  (1) 기록 — 한 자리를 정해 값을 적으세요
  (2) 생각 — 바로 위 두 수 를 더해 보세요
  (3) 판단 — 다른 자리 로 옮겨 다시 확인한 뒤 고르세요
      빈칸: n = {0} · r = {1} · C(n, r) = {2}
      빈칸: 위 두 수의 합 = {0} · C(n, r) 에서 그 합을 빼면 = {1}
      빈칸: 새 n = {0} · 새 r = {1} · C(n, r) − (위 두 수의 합) = {2}
      보기★ 한 사람을 정해 「뽑는다 / 안 뽑는다」 로 나누면 C(n,r) = C(n−1,r−1) + C(n−1,r) 가 된다
      보기  파스칼 삼각형은 규칙 없이 외워야 하는 표다
      보기  위 두 수를 더하는 것은 n 이 작을 때만 맞다

### LAB 143 — 똑같은 사탕을 나눠 담기 — 중복조합

### LAB 144 — 전개하지 않고 계수 찾기 — 이항정리
[오늘의 문제] $\\left(x + 2\\right)^{5}$ 를 다 전개하려면 괄호 다섯 개를 모두 곱해야 합니다. 그런데 $x^{2}$ 의 계수 하나만 알고 싶다면? 전부 전개하지 않고 집어낼 수 있을까요?
[화면 안내] 지수 n, 상수 c, 몇 번째 항 r 를 바꾸면 C(n, r) 와 계수 가 계산됩니다. 「계수를 모두 더하기」로 $\\left(1 + c\\right)^{n}$ 과 같은지도 볼 수 있습니다.하나하나 「넣는다 / 안 넣는다」 — 괄호 다섯 개에서 고르는 일과 같습니다.
[예상 1] 괄호 다섯 개에서 x 를 두 번 고르면 나머지는 무엇을 고르게 될지 적으세요.
[예상 2] 그렇게 고르는 방법이 몇 가지일지 예상하세요.
[예상 3] 계수를 모두 더하면 무엇이 될지 적어 보세요.
[미션 1] 「계수를 모두 더하기」 를 눌러 보세요.
[미션 2] n = 5, c = 2, r = 3 으로 맞춰 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 계수를 기록하고, 대칭을 견주고, 일반항을 판단합니다.
   └ 달성 신호: x 에 1 을 넣은 값
   └ 달성 신호: 의 계수는
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 지금 r 의 C(n,r) 과 계수 적기 ② r 을 n − r 로 바꿔 C 를 견주기 ③ 계수를 모두 더해 보기
   └ 손으로 쓸 것: 일반항이 C(n,r)·cʳ·$x^{n-}$ʳ 인 까닭을 「괄호마다 x 또는 c 를 고른다」로 설명하기
[탐구 1] n·c·r 을 바꿔 가며 5줄 이상 기록하세요.
[탐구 2] 「C(n,r)」와 「계수」가 다를 때가 있나요? 언제 같아지나요?
[탐구 3] 일반항을 손으로 써 보세요.
[기록표] n | c | r | C(n,r) | 계수
[힌트] 힌트 — 계수 = C(n, r) × cʳ 입니다. c = 1 이면 둘이 같습니다.
[적용] 새 문제 — $\\left(x + 2\\right)^{5}$ 를 전개했을 때 $x^{2}$ 의 계수 는?
[적용 답] 80 (허용오차 0.5)
[적용 해설] $x^{2}$ 이 되려면 괄호 다섯 개 중 x 를 두 번, 2 를 세 번 골라야 합니다. 고르는 방법 C(5,3) = 10 가지이고 $2^{3} = 8$ 이므로 10 × 8 = 80.
[적용 힌트] 괄호 5개 중 2 를 몇 번 골라야 $x^{2}$ 이 남나요? 그 방법의 수에 2 의 거듭제곱을 곱하세요.
[탐구 노트] 내가 고르고 · 내가 나누고 · 내가 판단한다
  (1) 기록 — 한 항을 정해 값을 적으세요
  (2) 생각 — 계수 ÷ C(n, r) 를 구하세요
  (3) 판단 — c 를 1 로 두고 r 을 n − r 로 바꾼 뒤 고르세요
      빈칸: n = {0} · c = {1} · r = {2} · C(n, r) = {3} · 계수 = {4}
      빈칸: 계수 ÷ C(n, r) = {0} · 그 값은 c 의 몇 제곱인가 = {1}
      빈칸: 새 r = {0} · C(n, r) = {1} · 계수 = {2}
      보기★ 일반항은 C(n, r)·cʳ·$x^{n-}$ʳ — 괄호마다 x 또는 c 를 고르는 방법의 수가 곧 계수다
      보기  계수는 늘 C(n, r) 와 같다
      보기  전개해 보기 전에는 계수를 알 수 없다

### LAB 145 — 배반이면 독립일까 — 헷갈리는 두 낱말
[오늘의 문제] 「동시에 일어나지 않는다」와 「서로 영향을 주지 않는다」 — 비슷하게 들리지만 정반대에 가까운 말입니다. 왜 그럴까요?

[예상 2] 독립이면 P(A∩B) 가 무엇과 같아야 할지 적으세요.
[예상 3] 배반이면서 독립일 수 있을지 예상하고 까닭도 적어 보세요.
[미션 1] 겹침을 0 으로 내려 보세요.
[미션 2] 겹침을 P(A)P(B) 와 같게 맞춰 보세요.

   └ 달성 신호: 곱과 같습니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 겹침을 0 으로 두고 판정 보기 ② 겹침을 곱과 같게 맞추기 ③ 두 경우의 P(A|B) 를 견주기

      보기  배반이면 자동으로 독립이다

### LAB 147 — 정확도 99% 인데 왜 안심하라 할까 — 조건부확률

### LAB 148 — 정말 관계가 있을까 — 2×2 표로 독립 판정
[오늘의 문제] 「아침을 먹는 학생은 지각을 덜 한다」 — 정말일까요? 표에 수를 적어 놓고 보면 관계가 있어 보이는 것과 정말 있는 것을 가를 수 있습니다.

[예상 1] 두 항목이 아무 관계가 없다면 네 칸의 수가 어떤 모양일지 적어 보세요.
[예상 2] 「기대도수」를 어떻게 구하면 좋을지 예상하세요.
[예상 3] 관측과 기대가 많이 다르면 무엇을 뜻할지 적으세요.
[미션 1] 네 칸을 기울여 관계가 세 보이게 만들어 보세요.
[미션 2] 「독립이 되도록 맞춰 주기」 를 눌러 보세요.
[미션 3] 아래 탐구 노트로 마무리하세요 — 표를 기록하고, 기대도수를 계산하고, 독립을 판단합니다.
   └ 달성 신호: 서로 영향을 준다고
   └ 달성 신호: 독립이라고 볼 만합니다
   └ 달성 신호: 탐구 노트 통과
   └ 해볼 것: ① 지금 네 칸과 $χ^{2}$ 적기 ② a 칸의 기대도수를 손으로 구하기 ③ 독립으로 맞춘 뒤 $χ^{2}$ 다시 보기
   └ 손으로 쓸 것: 기대도수 = 행 합 × 열 합 ÷ 전체 인 까닭을 「독립이면 곱」으로 설명하기
[탐구 1] 네 칸을 바꿔 가며 5줄 이상 기록하세요. 독립에 가까운 표도 만들어 보세요.
[탐구 2] 「$χ^{2}$」 열을 보세요. 언제 커지나요?
[탐구 3] 기대도수를 손으로 구해 관측과 견주세요.
[기록표] a | b | c | d | $χ^{2}$
[힌트] 힌트 — 독립이면 P(A∩B) = P(A)P(B) 이고, 사람 수로 고치면 행 합 × 열 합 ÷ 전체입니다.
[적용] 새 문제 — 아침 먹고 지각 안 함 40, 먹고 지각 10, 안 먹고 지각 안 함 35, 안 먹고 지각 15 일 때, 첫 칸의 기대도수 는?
[적용 답] 37.5 (허용오차 0.2)
[적용 해설] 아침을 먹은 사람 50명, 지각하지 않은 사람 75명, 전체 100명이므로 기대도수 = 50 × 75 ÷ 100 = 37.5. 관측 40 은 그보다 2.5 많습니다.
[적용 힌트] 행 합과 열 합을 먼저 구하고, 둘을 곱해 전체로 나누세요.
[탐구 노트] 내가 적고 · 내가 기대하고 · 내가 판단한다
  (1) 기록 — 네 칸을 기울여 $χ^{2}$ 를 크게 만들어 적으세요
  (2) 생각 — 첫 칸(a)의 기대도수 를 손으로 구하세요
  (3) 판단 — 「독립이 되도록 맞춰 주기」 를 누른 뒤 고르세요
      빈칸: a = {0} · b = {1} · $χ^{2}$ = {2}
      빈칸: 행 합 = {0} · 열 합 = {1} · 전체 = {2} · 기대도수 = {3}
      빈칸: 맞춘 뒤 a = {0} · $χ^{2}$ = {1}
      보기★ 독립이면 P(A∩B) = P(A)P(B) — 사람 수로 고치면 기대도수 = 행 합 × 열 합 ÷ 전체 다
      보기  $χ^{2}$ 가 0 이 아니면 반드시 관계가 있다

### LAB 151 — 100번에 60번 앞면, 의심할까 — 이항분포

[예상 2] 60번은 평균에서 얼마나 떨어진 것일지 예상하세요.
[예상 3] 얼마나 드물어야 「의심스럽다」고 할 수 있을지 적어 보세요.
[미션 1] k 를 오른쪽 끝 으로 밀어 보세요. 그런 결과가 얼마나 드문가요?

[미션 3] 아래 탐구 노트로 마무리하세요 — 꼬리를 기록하고, z 와 견주고, 기준을 판단합니다.

[탐구 노트] 내가 세고 · 내가 재고 · 내가 판단한다

      보기  n 이 커지면 z 가 작아진다
