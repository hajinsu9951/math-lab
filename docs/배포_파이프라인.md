# 배포 파이프라인 — 반드시 이 순서로

이 프로젝트는 **`src/` 하나로 끝나지 않습니다.**
빌드한 뒤 파이썬 스크립트를 차례로 얹어야 공개본이 됩니다.
LAB 01 의 「수학 노트」·힉스필드 썸네일은 **어느 `src/` 에도 없습니다.**

```bash
node build.mjs
python docs/썸네일_힉스필드/inject.py        dist/index.html docs/썸네일_힉스필드/labs_meta.json
python docs/LAB01_고도화/patch_lab1.py       dist/index.html
python docs/LAB02_고도화/patch_lab2.py       dist/index.html
python docs/LAB03_고도화/patch_lab3.py       dist/index.html
python docs/LAB21_고도화/patch_lab21.py      dist/index.html
python docs/LAB356_고도화/patch_lab356.py    dist/index.html
python docs/실습과제_연결/patch_flow.py      dist/index.html
python docs/썸네일_힉스필드/patch_publish.py dist/index.html
```

> **`patch_flow.py` 는 `patch_lab2.py` 뒤에 두십시오.** LAB 02 가 「단어 가중치」에서
> 「100통 분할표」로 바뀌면서 타임라인·labuse·세특 예시의 문구를 함께 고치기 때문입니다.

**패치 스크립트는 몇 번을 돌려도 됩니다.** 자리표시자를 다시 찾아 덮어쓰므로, 삽화가 나중에 도착하면
그림만 `docs/썸네일_힉스필드/상황삽화/` 에 넣고 같은 명령을 한 번 더 돌리면 됩니다.

## patch_publish.py 가 넣는 것

1. **📌 다시 보는 오늘의 문제** — 예상·실험·기록 단계 머리에. 단계를 넘겨도 문제가 안 사라집니다.
2. **「풀이와 답안」 안내 줄** — 무엇을 쓸지 ①②③ 으로. 예상·원리·보고서 문구가 각각 다릅니다.
3. **카드 격자** — `.wrap`(1140px)을 격자만 벗어나게 해 4열 → 6~7열, 카드 비율 0.76 → 0.80.
   썸네일 그림 비율은 **건드리지 않습니다** (2.2:1 로 잘랐다가 삽화가 상해 되돌렸습니다).
4. **탐구 사다리 답 숨김 + 틀린 칸 표시** — 「▸ 이렇게」 줄에 정답 식이 그대로 적혀 있던 것을
   절차만 남기고 지웁니다. 「식 확인」을 누르면 **틀린 칸만** 붉게 하고 오류별 힌트를 줍니다.
