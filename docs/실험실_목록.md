## 연수 개요

> 아래는 제출한 **프로그램 계획서(약안)** 에서 그대로 읽어 온 것입니다.

### 교육 목표

- 실생활 맥락(GPS 측위·스팸 필터·정보 확산)에서 수학 원리를 끌어내어 AI·디지털 기반 교수학습 과정을 설계할 수 있다.
- 생성형 AI와 디지털 도구(GeoGebra·Desmos·스프레드시트)를 활용해 학생이 직접 조작하는 인터랙티브 웹 수업자료를 제작하고 수업·평가에 적용할 수 있다.

### 기대 효과

- 코딩 경험이 없는 교사도 3시간 안에 담당 단원용 인터랙티브 웹 자료 1종을 완성하여 다음 수업에 즉시 투입할 수 있다.
- ‘실생활 맥락 → 수학 원리 → 디지털 도구 → 자료 제작 → 평가·윤리’로 이어지는 재사용 가능한 설계 절차를 체득하여 타 단원으로 확장 적용할 수 있다.

### 1. [체험·해체] “여기 어디지?” ― GPS 삼변측량으로 여는 좌표기하 수업 설계 · 1H

- 실생활 질문에서 수학 원리를 끌어내는 수업 설계 절차(맥락→원리→도구→자료) 이해
- GeoGebra·Desmos로 세 원의 교점(=내 위치)을 시각화하고, 측정 오차에 따라 위치가 ‘오차 영역’으로 번지는 과정 관찰
- 완성 웹자료 「일상 속 수학 실험실」을 직접 조작한 뒤 구조 해체하기(입력–계산–시각화–피드백 4블록)

### 2. [제작] “이 문자, 스팸일까?” ― 생성형 AI로 만드는 인터랙티브 수학 웹자료 · 1H

- 조건부확률·베이즈 정리를 작은 표로 손계산한 뒤 스프레드시트로 나이브 베이즈 분류기까지 확장
- 수학 자료용 프롬프트 3요소(수학 원리·학생 조작 요소·즉시 피드백)를 적용해 단일 HTML 파일 생성
- 생성 결과 검증·수정(수식 오류 점검, 슬라이더·정답 확인 기능 추가) 후 브라우저에서 즉시 실행

### 3. [적용·나눔] “왜 순식간에 퍼질까?” ― 내 단원으로 갈아끼우고 공유·성찰하기 · 1H

- 지수·로지스틱 확산 시뮬레이터를 담당 단원 자료로 리모델링(데이터·변수·난이도 교체)
- 학습지·평가 루브릭·수업 흐름표를 한 세트로 묶어 수업 적용안 완성
- 갤러리 워크로 상호 피드백, 공유 링크(QR) 발급 및 데이터 출처·프라이버시 등 AI 활용 윤리 체크리스트 작성

### 1차시 · “여기 어디지?” ― GPS와 삼변측량으로 배우는 좌표기하

| | |
|---|---|
| 역량 | A (AI·디지털 이해 및 교육적 활용) |
| 교수학습 목표 | 교사는 삼변측량의 원리를 원의 방정식과 연립방정식으로 설명할 수 있으며, GeoGebra·Desmos로 위치 추정을 시각화하고 인터랙티브 자료로 제작하여 좌표기하의 실생활 적용 수업을 설계할 수 있다. |

**맥락과 원리**

- 실생활 맥락 : 내비게이션·배달앱이 내 위치를 콕 집는 법, 재난문자·실종자 위치 추적, 와이파이 실내 측위
- 핵심 수학 원리 : 좌표평면과 두 점 사이의 거리, 원의 방정식, 세 원의 교점(연립방정식), 측정 오차가 있을 때의 최적 추정(최소제곱의 직관)
- AI·디지털 연계 : 위치기반 서비스(LBS), 센서 융합·위치 보정 AI가 딛고 선 수학적 토대

**교수학습 방법**

- 강의(20%) : 두 점 사이의 거리·원의 방정식·삼변측량의 원리를 실제 측위 사례로 압축 설명
- 실습(50%) : GeoGebra로 세 원의 교점=내 위치 찾기 → 거리에 오차를 줄 때 교점이 ‘오차 삼각형’으로 흩어지는 현상 관찰 → 위치 추정 인터랙티브 HTML 제작
- 협력학습(20%) : 교실 좌표계에서 거리 단서로 ‘기준점(보물)’을 찾는 탐구 활동을 모둠별로 설계
- 토의·토론(10%) : 위치 추적의 편익과 프라이버시(감시) 사이의 균형에 대한 토의

**교수학습 활동**

- 활동 1. [동기 유발] 내 스마트폰의 위치 정확도를 확인하고 “어떻게 알아낼까?”를 추측하며 측위 문제를 끌어낸다.
- 활동 2. [개념·실습] 세 기준점과 거리로 원 3개를 그려 교점=내 위치를 찾고(GeoGebra), 거리에 오차가 있을 때 위치가 ‘오차 영역’으로 번지는 것을 관찰한다.
- 활동 3. [자료 제작] 기준점·거리를 입력하면 추정 위치가 표시되는 인터랙티브 HTML을 제작하고, ‘교실 보물찾기’ 수업안을 작성한다.

**평가 루브릭**

| 평가 요소 | 상 / 중 / 하 |
|---|---|
| 원리 이해 | 삼변측량을 원의 방정식·연립으로 설명함 / 부분적으로 설명함 / 용어 나열에 그침 |
| 도구 활용 | 교점·오차 영역을 시각화해 산출함 / 일부 산출함 / 산출 미흡 |
| 자료 제작 | 작동하는 HTML과 수업안을 완성함 / 둘 중 하나만 완성 / 미완성 |

**준비물** — 팀별 : 노트북, 교실 좌표 측정 도구(줄자·모눈종이 등) · 개인별 : 구글 계정(GeoGebra·Desmos), 위치 정확도 확인용 스마트폰

- 토의·토론(15%) : 정상 문자를 스팸으로 막는 오류(거짓양성)의 책임과 필터의 프라이버시 쟁점 토론

**교수학습 활동**

- 활동 1. [동기 유발] 스팸문자 모음에서 자주 나오는 단어를 찾고 “수학으로 가려낼 수 있을까?”를 던진다.

- 활동 3. [자료 제작] 문자를 입력하면 스팸확률을 보여주는 인터랙티브 HTML을 제작하고, 확률 단원 적용안을 작성한다.

**평가 루브릭**

| 도구 활용 | 분류기를 구축하고 정확도를 확인함 / 일부 구축함 / 산출 미흡 |

### LAB 01 · “여기 어디지?” GPS 위치 추정

> 스마트폰은 내가 어디 있는지 어떻게 알까?

| | |
|---|---|
| 수학 개념 | 좌표평면·두 점 사이의 거리 · 원의 방정식 · 연립방정식 |
| AI · 실생활 | 위치기반서비스(LBS) · 센서 융합·오차 보정 |
| 핵심 식 | (x − a)² + (y − b)² = r² |

**무엇을 보는가** — 기준점에서 잰 거리가 r 이라는 사실 하나는 “나는 그 점을 중심으로 반지름 r인 원 위에 있다”는 뜻입니다. 기준점이 둘이면 두 원의 교점 두 곳으로, 셋이면 한 점으로 좁혀집니다. 위치를 찾는 일이 원의 방정식 연립으로 바뀌는 순간입니다.

**조작 안내** — 기준점 3개까지 늘려 보세요. 원 1개 → 2개 → 3개로 갈수록 내 위치가 한 점으로 좁혀지는 과정이 그대로 보입니다. 오차를 키우면 교점이 “오차 삼각형”으로 번지는데, 이때 “가장 그럴듯한 위치”를 찾는 것이 곧 최소제곱의 직관입니다.

- **바로** 우리 동네 좌표로 바꿔 보기
- **심화** 기준점 2개로는 왜 안 되는가
- **프로젝트** 교실 안 실내 측위 만들기

- **심화** 왜 음수 × 음수 = 양수인가

**무엇을 보는가** — 다면체와 회전체는 만든 방법이 다릅니다. 다면체는 평면 조각을 붙여 만들고, 회전체는 평면도형을 축 둘레로 돌려 만듭니다. 그 차이가 단면에 그대로 나타납니다 — 회전체의 단면은 언제나 원입니다.
