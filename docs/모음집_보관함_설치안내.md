# 우리 연수 모음집 — 공동 보관함 설치 안내

연수가 끝나 페이지를 닫아도 선생님들이 만든 자료가 남고,
나중에 **우수 사례를 골라 올리고 꺼내 볼 수 있도록** 하는 장치입니다.

한 번만 만들어 두면 다음 연수에도 그대로 씁니다. **무료·무기한**입니다.

---

## 세 가지 저장 방법 — 무엇을 언제 쓰나

| 방법 | 버튼 | 언제 쓰나 | 인터넷 |
|---|---|---|---|
| ① 모음집 내려받기 | `모음집 내려받기 (HTML 하나)` | 연수 마무리 · 전원에게 배포 | 불필요 |
| ② 작업 저장 | `작업 저장 (.json)` / `작업 불러오기` | 오늘 작업을 다음에 이어서 | 불필요 |
| ③ 공동 보관함 | `보관함에 올리기` / `보관함에서 가져오기` | 연수 뒤 우수 사례 누적 | **필요** |

**①②는 지금 바로 작동합니다.** ③만 아래 설치가 필요하고,
설치하지 않아도 화면의 나머지 기능은 전부 그대로 돌아갑니다.

> 연수장 와이파이가 끊겨도 진행에 지장이 없도록 이렇게 나눠 두었습니다.

---

## 설치 — 10분

### 1. 스프레드시트 만들기

구글 드라이브에서 **새로 만들기 → Google 스프레드시트**.
이름은 아무거나 (예: `2026 대전 AI연수 수학 — 연수 모음집`).

시트 두 장(`목록`·`조각`)은 **자동으로 만들어지므로** 손댈 것이 없습니다.

### 2. Apps Script 붙여넣기

스프레드시트에서 **확장 프로그램 → Apps Script**.

`Code.gs` 의 내용을 모두 지우고, 같은 폴더의 **`모음집_보관함.gs`** 전문을 붙여넣습니다.
저장(💾).

### 3. 배포

오른쪽 위 **배포 → 새 배포**

| 항목 | 고를 것 |
|---|---|
| 유형 | **웹 앱** |
| 설명 | 아무거나 (예: `연수 모음집 v1`) |
| 다음 사용자로 실행 | **나** |
| 액세스 권한 | **모든 사용자** ← 중요 |

> **모든 사용자**로 해야 참가자가 로그인 없이 올릴 수 있습니다.
> 처음 배포할 때 권한 승인 창이 뜹니다 — *고급 → 안전하지 않은 페이지로 이동* 을 거쳐 허용하십시오.
> (내가 만든 스크립트라 나오는 경고입니다.)

배포가 끝나면 이런 주소가 나옵니다:

```
https://script.google.com/macros/s/AKfycb.../exec
```

### 4. 주소 넣기

**방법 A — 그때그때 (설치 불필요)**
탭⑤ 의 `공동 보관함` 을 펼치고 주소 칸에 붙여넣으면 바로 버튼이 켜집니다.

**방법 B — 아예 박아 두기 (권장)**
`src/80-gallery.js` 16번째 줄

```js
const GAL_URL = '';
```

에 주소를 넣고 다시 빌드합니다.

```bash
node build.mjs
```

이러면 참가자는 주소를 입력할 필요 없이 버튼만 누르면 됩니다.

## 쓰는 법

**연수 중** — 선생님들이 자료를 올린 뒤 `보관함에 올리기` 한 번.
이미 올라간 것은 다시 올라가지 않습니다.

**연수 뒤** — 페이지를 새로 열고 `보관함에서 가져오기` 를 누르면 그동안 쌓인 것이 전부 들어옵니다.
거기서 우수 사례를 골라 `확장 카탈로그로 보내기` → `카탈로그 추가분 내보내기` 로
`55-catalog.js` 에 영구히 넣습니다.

---

## 알아둘 것

- **자료 하나 2MB 제한** — 화면 쪽 제한과 같습니다. HTML 본문은 4만 자씩 쪼개 여러 줄에 나눠 담습니다(구글 셀 한도가 5만 자).
- **동시에 눌러도 안전** — `LockService` 로 줄이 섞이는 것을 막습니다.
- **개인정보** — 제작자 칸에 실명이 들어갑니다. 대외 공개 전에 마스킹하십시오.
- **보관함이 죽어도 화면은 멈추지 않습니다** — 실패하면 메시지만 뜨고 메모리 모드로 계속 진행됩니다.
- **삭제·수정 기능은 없습니다** — 잘못 올린 줄은 스프레드시트에서 직접 지우십시오(`목록`·`조각` 양쪽에서 같은 id).

## 되는지 확인

배포 주소 뒤에 `?mode=list` 를 붙여 브라우저로 열어 봅니다.

```
https://script.google.com/macros/s/AKfycb.../exec?mode=list
```

`[]` 가 나오면 정상입니다. (아직 올린 것이 없다는 뜻)
`{"error": …}` 나 로그인 화면이 나오면 **액세스 권한이 「모든 사용자」인지** 다시 확인하십시오.
