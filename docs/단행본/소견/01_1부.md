## 사실 확인에서 바로잡은 것 — 네 건

| 처음 쓴 것 | 확인 결과 | 고친 자리 |
|---|---|---|
| 안티키테라 기계에 **톱니 223 개**인 바퀴가 있다 | 확인되지 않음. 223 은 **뒷면 나선의 눈금 칸 수**(사로스 223 삭망월). 앞면 메톤 눈금은 235 칸 | 2장 연표 |
| 파스칼이 **「0 에서 4 를 빼면 0 이다」** 라고 말했다 | 직접 인용 확인 안 됨. 클라인이 전하는 **「비웃었다」** 로 바꾸고 「전해집니다」로 적음 | 3장 이야기·연표 |
| 브라마굽타가 **「빚에서 빚을 빼면 재산」** 이라 적었다 | 확인된 규칙은 **「0 에서 빚을 빼면 재산」**. 「음수를 처음 정리」도 뺌(『구장산술』이 더 이름) | 3장 세 곳 |
| RSA-129 가 **17년** 만에 깨졌다 | 1977년 8월 → 1994년 4월 = **16년 8개월** | 1장 이야기 |

그 밖에 매미의 소수 주기는 **포식자 포화가 더 잘 뒷받침되고 소수 부분은 논쟁 중**이라는 사실을 본문에 넣었다(2장). 데카르트가 왜 하필 x 를 골랐는지에 대한 「인쇄소 활자」 이야기는 확인되지 않아 **적지 않았다**(4장).

## ① 교실 운영

- **화면 이름 대조** — 남은 4 곳은 모두 기계의 한계이거나 내 수사다.
  「곱하기 — 클릭 두 번이면 끝」은 **캔버스에 그린 글**이라 textContent 로 안 읽히고,
  「찾았습니다!」는 **조작한 뒤에야** 나오는 글이다. 「왜 아무 두 소수나 쓰지 않는가」와
  「쌓이는 규칙」은 화면 이름이 아니라 본문의 표현이다. → 눈으로 확인했고 모두 맞다.
- **분량** — 장당 18.5 쪽. 목표(18~22 쪽)에 들어 있다.
- **되돌리기 단추** — 4장에서 「− 한 칸」을 꼭 눌러 보게 했다. 늘리기만 하면 규칙을 「쌓는 것」으로만
  보게 되는데, 줄여 보아야 양방향임을 안다. 이 지시를 앞으로도 모든 장에 넣는다.

## ② 교육과정과 평가

- 4장의 용어 셋(문자의 사용 · 식의 값과 대입 · 일차식)은 모두 중1 「변화와 관계」 범위다.
- **선행 경계** — 「수학적 귀납법」은 더 깊이 박스 안에서 이름만 꺼내고 **「고등학교에서 배운다」**
  고 밝혔다. √ 기호(1장)도 같은 방식으로 처리했다.
- **연습문제 재계산** — 4장 확장형(2 × n 격자) 답 5n + 2 를 손으로 검산했다.
  n = 1 → 7 ✓(가로 3 + 세로 4), n = 2 → 12 ✓(가로 6 + 세로 6).
  「두 줄이면 두 배일 것」이라는 오해를 깨는 자리이므로 풀이에 6n + 2 − n = 5n + 2 를 적어 두었다.
- 적용 301 ✓ · 계산형 n=1, n=20 검산 ✓ · 해석형은 **오답을 분석하게 하는** 문항이다.

## ③ 엄밀성

- 4장의 사실 주장 **열 건 모두 출처를 달았다**. 카조리 『수학 기호의 역사』(1929)가 기호의
  첫 사용을, 카츠 『수학의 역사』가 알콰리즈미 원문을 뒷받침한다.
- **과장 점검** — 「비에트가 문자를 처음 썼다」로 쓰지 않았다. 13세기 요르다누스, 16세기
  슈티펠·카르다노가 앞섰고, **비에트의 몫은 그것을 대수의 바탕으로 삼은 것**이라고 적었다.
- 모저의 원 문제(1, 2, 4, 8, 16, **31**)를 넣어 「몇 개 보고 짐작한 규칙」의 위험을 보였다.
  수를 확인했고 출처를 달았다.
