## 1. 휴대폰에서 화면이 여러 겹으로 겹쳐 보이던 것 — 고쳤다

**무엇이 문제였나.** 폰(375 px)으로 열어 확인해 보니 겹쳐 보이게 만드는 까닭이 셋이었다.

| | 증상 | 까닭 |
|---|---|---|
| ① | 실험실을 열어 놓고 손으로 밀면 **뒤 페이지가 같이 움직였다** | 모달이 열려도 뒤 페이지 스크롤을 세우지 않았다. 탭 줄·어두운 막·뒤 카드 세 겹이 동시에 움직였다 |
| ② | 「학생이 보는 화면」 칸이 **화면에 붙어 아래를 덮었다** | `.pvcol`·`.preview` 가 `position:sticky`. 폰에서는 한 칸으로 접히므로 붙박이가 겹침만 만든다 |
| ③ | 카드의 꼬리표 아랫줄이 **「▶ 직접 조작해 보기」와 겹쳤다** | 꼬리표를 한 줄로 잘라 두었는데(`max-height:24px`) 폰에서는 두 줄이 되었다 |

**어떻게 고쳤나.** 전부 폭 조건 안에 넣어 **데스크톱 화면은 건드리지 않았다.**

- ① `#mask` 의 class 를 지켜보다가 열리면 뒤 페이지를 그 자리에 세우고(`body.mlock`),
  닫으면 보던 자리로 되돌린다. **폰(≤940 px)에서만** 건다.
- ② `≤940 px` 에서 `.pvcol`·`.preview` 의 sticky 를 푼다.
- ③ `≤760 px` 에서 꼬리표를 줄 수대로 보이게 둔다. 카드가 335 px → 380 px 로 자란다.
- 덤으로 폰에서만: 탭 줄 불투명 처리(반투명+흐림이 뒤를 비쳤다), 모달 여백 24 → 8 px,
  `.col` 의 `min-width:280px` 해제(폰 너비를 넘었다), 채팅·코드 칸 안쪽 스크롤 축소,
  미리보기 iframe 520 px → 62 vh.

**확인한 것.** 폰 375 px — 꼬리표 846~902 · 「직접 조작해 보기」 912~932 로 **떨어졌다**.
모달을 열면 `body.mlock` 이 붙고 뒤 페이지가 0 px 도 움직이지 않으며, 닫으면 보던 600 px 로 돌아온다.
데스크톱 1280 px — 카드 높이 323 px · sticky · 흐림 **그대로**.

**고친 파일**

```
math-lab/src/99-foot.html      ← 맨 끝 <!-- MOBILE PATCH --> 묶음 (CSS + 스크립트)
math-lab/dist/index.html       ← 다시 빌드한 배포본 (32.9 MB)
```

빌드는 **반드시 이 순서**다. 순서를 바꾸면 활동지 LaTeX 손질이 지워진다.

```bash
node build.mjs && python docs/활동지/patch_worksheet.py dist/index.html
```

**깃허브.** 공개본(`main` 가지의 `index.html`)까지 올렸다 — `5cde0b3`.
작업 가지 `v326-사다리` 에는 `4bbbcba` 로 올렸다.
공개 주소에서 `MOBILE PATCH` 와 활동지 손질(`wsTex` 20 곳)이 모두 들어 있는 것을 확인했다.

## 2. 단행본 본문 글꼴 — 본명조로 통일했다

`docs/단행본/book.css` 의 `:root{--serif:…}` 한 곳에서만 정한다.

```
본명조 → Source Han Serif K → Noto Serif KR → 나눔명조 → KoPub바탕체 Medium → 함초롬바탕
```

읽는 책의 본문은 명조라야 눈이 덜 피곤하다. 고딕(Pretendard)은 화면·연수 자료의 글꼴로 둔다.
**그림 안 글씨(`figures.py` 의 `FONT`)는 고딕으로 남겼다** — 작은 글씨는 고딕이 더 읽힌다.

> 다만 **이 데스크톱에는 본명조가 설치되어 있지 않다.** 지금 PDF 는 **나눔명조**로 떨어져 나온다.
> 설치된 명조 계열: HY견명조 · HY신명조 · KoPub바탕체 · 나눔명조 · 함초롬바탕 · 휴먼명조.
> 본명조를 깔면 아무것도 고치지 않아도 그대로 본명조로 나온다.

## 3. 그림 안 글씨가 겹치던 것 — 세어서 고쳤다

보내 주신 「지수 표」 그림에서 **「12」와 「2²」가 포개져** 읽히지 않았다.
눈으로 찾지 않고 **기계로 세도록** 검사기를 새로 만들었다.

```
docs/단행본/check_fig.py   ← 새로 만든 것
python docs/단행본/check_fig.py            49 장 전부 센다
python docs/단행본/check_fig.py ch02_expo  한 장만 센다
```

`<text>` 하나하나의 자리를 글자 폭으로 재어, 네 변이 4 px 넘게 포개지는 짝을 찾는다.

**49 장을 돌려 다섯 곳이 걸렸고, 둘 다 고쳤다.**

| 그림 | 겹친 것 | 까닭 · 손질 |
|---|---|---|
| `ch02_expo` | 「12 =」⟂「2²」, 「18 =」⟂「2¹」 | 줄 이름을 오른쪽 맞춤으로 x=248 에 찍었는데 지수 칸(x=240)과 겹쳤다. 이름 칸을 왼쪽(x=100)으로 떼고 지수 칸을 300·410·530 으로 밀었다 |
| `ch12_count` | 1975·1977, 2015·2017 의 설명이 포개짐 | 2 년 차이라 점이 붙는다. 위아래로만 엇갈려서는 안 되어 **좌우로도 비켜** 세웠다. 오른쪽 끝 「15」는 「15 종」으로 바꿔 아래로 내렸다 |

**지금 상태: 그림 49 장 · 겹침 0 곳.**
