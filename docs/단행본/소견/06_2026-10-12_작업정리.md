## 1. 휴대폰에서 화면이 여러 겹으로 겹쳐 보이던 것

폰(375 px)으로 직접 열어 확인했더니 까닭이 셋이었습니다.

| | 증상 | 까닭 |
|---|---|---|
| ① | 실험실을 열어 놓고 손으로 밀면 **뒤 페이지가 같이 움직였다** | 모달이 열려도 뒤 페이지 스크롤을 세우지 않았다. 탭 줄·어두운 막·뒤 카드 세 겹이 동시에 움직였다 |
| ② | 「학생이 보는 화면」 칸이 **화면에 붙어 아래를 덮었다** | `.pvcol`·`.preview` 가 sticky. 폰에서는 한 칸으로 접히므로 붙박이가 겹침만 만든다 |
| ③ | 카드 꼬리표 아랫줄이 **「▶ 직접 조작해 보기」와 겹쳤다** | 꼬리표를 한 줄로 잘라 두었는데 폰에서는 두 줄이 되었다 |

전부 폭 조건(≤760·≤940 px) 안에 넣어 **데스크톱 화면은 건드리지 않았습니다.**
확인: 폰 375 px 에서 꼬리표 846~902 · 「직접 조작해 보기」 912~932 로 **떨어졌고**,
모달을 열면 뒤 페이지가 0 px 도 움직이지 않으며 닫으면 보던 자리로 돌아옵니다.
데스크톱 1280 px 은 카드 높이 323 px · sticky · 흐림 **그대로**입니다.

```
math-lab/src/99-foot.html      맨 끝 <!-- MOBILE PATCH --> 묶음
math-lab/dist/index.html       다시 빌드한 배포본
```

빌드는 **반드시 이 순서**입니다. 바꾸면 활동지 LaTeX 손질이 지워집니다.

```bash
node build.mjs && python docs/활동지/patch_worksheet.py dist/index.html
```

**깃허브** — 공개본(`main` 의 `index.html`)까지 올렸습니다(`5cde0b3`). 작업 가지는 `v326-사다리`.

### 그림 글씨 겹침 — 기계로 센다

보내 주신 「지수 표」에서 **「12」와 「2²」가 포개져** 읽히지 않았습니다.
눈으로 찾지 않도록 검사기를 만들었습니다.

```bash
python docs/단행본/check_fig.py            57 장 전부

```

`<text>` 하나하나의 자리를 글자 폭으로 재어 네 변이 4 px 넘게 포개지는 짝을 찾습니다.
**다섯 곳이 걸렸고 모두 고쳤습니다.**

| 그림 | 겹친 것 | 손질 |
|---|---|---|
| `ch02_expo` | 「12 =」⟂「2²」, 「18 =」⟂「2¹」 | 이름 칸을 왼쪽으로 떼고 지수 칸을 밀었다 |
| `ch12_count` | 1975·1977, 2015·2017 의 설명이 포개짐 | 위아래만이 아니라 **좌우로도** 비켜 세웠다 |

**지금 그림 57 장 · 겹침 0 곳.**

### 화면 사진을 다시 찍었습니다

캡처라 해상도가 낮다고 하신 것, 원인이 둘이었습니다.

- **넓게 찍어서** — 1280 px 로 찍은 화면을 17 cm 단에 넣으면 글씨가 너무 작아집니다.
- **JPEG 라서** — 화면 글자처럼 테두리가 또렷한 그림은 JPEG 가 뭉갭니다.

그래서 **1000 px · 3 배 해상도 · PNG** 로 바꿔 40 장을 다시 찍었습니다(3.8 MB → 7.3 MB).
좁게 찍으면 같은 자리에서 글씨가 1.3 배 커집니다.
