그림만 넣으면 겉만 좋아집니다. 아래가 실제로 수업을 끊는 지점입니다.

### LAB 02 — 여섯 곳

| # | 끊긴 곳 | 고칠 방향 |
|---|---|---|
| 1 | 문제는 두 문장(「[무료] 대출 당첨」·「내일 회의 자료」)을 묻는데 **실험에서 그 두 문장을 판정하지 않는다** | 미션 0 으로 그 두 문장을 먼저 판정하게 |
| 2 | 예상은 「무료+회의」 조합을 묻는데 **미션에 그 조합이 없다** | 예상에서 세운 식을 노트에 그대로 입력 (LAB 01 방식) |
| 3 | 화면이 「무료 0.92」처럼 **완성된 확률**을 준다 — 그 값의 출처가 없다 | **100통 분할표**를 띄우고 세어서 구하게 |
| 4 | 「나이브」가 **왜** 나이브인지(독립 가정) 묻지 않는다 | 미션 3 을 "함께 나오는 두 단어를 곱해도 되나?"로 |
| 5 | 적용이 0.9×0.1/(0.9×0.1+0.1×0.9)=0.5 **한 번 계산으로 끝난다** | 희귀 질병 검사로 교체 |
| 6 | 원리의 「거짓양성」이 **실험에 장치가 없다** | 스팸 비율 슬라이더(20%→1%) 추가 |

#### LAB 02 에 넣을 분할표 (손으로 검산되는 정수)

| | 스팸 20통 | 정상 80통 |
|---|---|---|
| 「무료」 있음 | 16 | 4 |
| 「무료」 없음 | 4 | 76 |

```
P(스팸) = 20/100 = 0.2
P(무료|스팸) = 16/20 = 0.8      P(무료|정상) = 4/80 = 0.05
P(스팸|무료) = 0.8×0.2 / (0.8×0.2 + 0.05×0.8) = 0.16 / 0.2 = 0.8
```

### LAB 03 · 21 에 넣을 식 검사 (참고 수치)

- **LAB 03** — N(t)=N₀(1+r)^t, 배가시간 T = log2 / log(1+r).
