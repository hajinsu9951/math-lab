## 강의용 PPT

3시간(180분) 연수를 그대로 진행할 수 있는 슬라이드 152장입니다.

<https://hajinsu9951.github.io/math-lab/2026_대전_AI연수_수학_3시간_강의.pptx>

1교시 체험·해체(GPS 삼변측량) · 2교시 제작(스팸 분류기로 배우는 바이브 코딩 7라운드) ·
3교시 적용·나눔(내 단원 리모델링과 수행평가 설계)으로 짜여 있습니다.
종수 문구는 손으로 적지 않고 웹페이지 소스에서 읽어 씁니다 — 실험실을 늘리면 슬라이드도 따라 바뀝니다.

글꼴은 충남대 사업단 제공 슬라이드 마스터가 지정한 **Freesentation** 입니다.
설치되어 있지 않으면 다른 글꼴로 대체되어 열립니다.

## 무엇이 들어 있나

- **수학 실험실 356종** — 중1부터 전문 수학까지. 하나하나가
  ① 오늘의 문제 → ② 예상 메모 → ③ 탐구 사다리 5단계 → ④ 탐구 보고서 로 이어집니다.
- **탐구 사다리** — 다섯 단계 가운데 둘 이상은 학생이 실제로 조작해야 넘어갑니다.
  버튼만 눌러서는 넘어가지지 않습니다. 마지막 단계는 손으로 쓰는 심화입니다.
- **탐구 보고서** — 조작한 값이 표에 쌓이고, 그대로 한 장으로 저장해 제출할 수 있습니다.
- **확장 카탈로그 577종** — 만들어 둔 356종과, 수업 설계에 쓰라고 정리해 둔
  설계 재료 221종(「설계 재료 보기」를 눌러야 나옵니다).
- **문제 해결 수업 모형 22종** — LAB 01~21 과 356 은 문제 → 예상 → 실험 → 기록·발견 →
  원리 → 적용 → 정리 일곱 단계로 열립니다. 앞 단계를 넘어야 다음이 열립니다.
- **LAB 356 논리 회로 탐정** — 상자를 열지 않고 회로를 알아냅니다. 회로 9종의 진리표를
  실험으로 채우고, 게이트 블록으로 같은 판정을 내는 회로를 조립해 검사합니다.
  같은 진리표를 내는 다른 조립을 찾으면 드모르간·분배·결합 법칙이 학생의 식에서 나옵니다.
  (대전대신고 「인공지능 수학」 3차시 연구수업 자료를 실험실 안으로 옮겨 온 것입니다.)
- **바이브 코딩 실습 · 3시간 운영 흐름 · 수업·평가 설계 · 연수 모음집**

## 만든 방식

단일 HTML 한 장입니다. 외부 라이브러리도, 인터넷 연결도 쓰지 않습니다.
그림은 전부 canvas 와 SVG 로 그리고, 수식은 자체 변환기로 MathML 로 만듭니다.
연수장 노트북이 어떤 상태든 열리도록 그렇게 만들었습니다.
