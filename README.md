# 일상 속 수학 실험실

> 2026 대전광역시교육청 인공지능 활용 선도교사 연수 · 중등 수학
> **AI·디지털 기반 교수학습 설계 및 자료 제작(수학)** — 3차시 실습 웹자료

중·고등학교 수학 교사가 **코드를 한 줄도 쓰지 않고** AI와 대화만으로
수업용 인터랙티브 학습자료를 만들어 보는 실습 페이지입니다.

## 바로 쓰기

`dist/index.html` 을 브라우저로 여세요. 그게 전부입니다.
설치도, 서버도, 로그인도 필요 없습니다.

## 개발하기

```bash
npm install     # 최초 1회 (검증용 playwright)
npm run build   # src/* → dist/index.html
npm test        # 10종 × 7라운드 = 70개 상태 자동 검증
```

## Claude Code로 이어서 작업하기

이 폴더에서 터미널을 열고

```bash
claude
```

를 실행하면 됩니다. `CLAUDE.md` 에 프로젝트 구조·규칙·실험실 추가 방법이
정리되어 있어 바로 이어서 작업할 수 있습니다.

예를 들어 이렇게 요청하세요.

- "삼각비를 쓰는 실험실을 하나 추가해 줘. 4라운드에는 눈에 보이는 결함을 심어 줘."
- "GPS 실험실의 6라운드 활동을 모둠 대결 형태로 바꿔 줘."
- "탭③ 타임라인을 2시간짜리 축약 버전으로도 만들어 줘."
- "npm test 돌려서 실패하는 라운드 고쳐 줘."

## 구성

| 탭 | 내용 |
|---|---|
| ① 수학 실험실 10종 | 작동하는 인터랙티브 자료 10개 (GPS·베이즈·확산·룬·회귀·경사하강·몬테카를로·코사인유사도·합성곱·파형) |
| ② 바이브 코딩 실습실 | 10종 전부를 AI와 7라운드 대화로 만들어 보는 실습 + 클릭 조립(참고용) |
| ③ 3시간 운영 흐름 | 체험 → 개조 → 생성 3단 사다리와 타임라인 |
